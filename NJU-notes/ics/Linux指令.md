#### 1. 文件系统导航与操作（最基础的“手脚”）

- ls -la：列出当前目录下的所有文件。-l 显示详细信息（权限、大小、修改时间），-a 显示隐藏文件（比如 .git、.gitignore）。
    
- cd <路径>：切换目录。
    
- pwd：显示当前所在的绝对路径（当你迷失在多级深层目录时，用它定位）。
    
- mkdir -p <文件夹名>：创建文件夹。-p 允许递归创建多层未存在的目录（如 mkdir -p a/b/c）。
    
- rm -rf <文件或文件夹>：**（高危命令，务必小心！）** 强制且递归地删除文件或文件夹。Linux 没有回收站，运行该命令后数据直接从磁盘抹去，无法撤销。
    

#### 2. 代码检索与分析（ICS 实验的“显微镜”）

- grep -rn "要找的变量名" <目录>：**极度常用**。在指定目录的所有文件中，递归 (-r) 查找包含某个变量、函数或字符串的行，并显示行号 (-n)。
    
    - 场景：NEMU 的代码非常庞大。当你不知道某个宏定义或者结构体在哪个文件里声明时，用它一秒定位。
        
- find . -name "*.c"：在当前目录 . 下，查找所有以 .c 结尾的文件。
    

#### 3. 进程监控与清理（收拾“烂摊子”的工具）

在做 ICS 实验（尤其是溢出攻击或模拟器）时，由于 C 语言指针和死循环的问题，你的程序经常会卡死或变成僵尸进程。

- top 或 htop：类似 Windows 的任务管理器，实时查看哪些进程把 CPU 占满了（按 q 键退出）。
    
- ps aux | grep nemu：在系统所有运行的进程中，过滤出名字包含 nemu 的进程。它会展示该进程的 **PID（进程标识符）**。
    
- `kill -9  <PID>` ：如果你的程序卡死且无法用 Ctrl + C 终止，用这行命令强制杀掉指定 PID 的进程。


#### 4. 打包与解压（获取与提交实验数据的工具）

学校发布的实验包通常是 .tar.gz 格式。

- `tar -xzvf <文件名.tar.gz>` : 解压并展开一个 `.tar.gz` 压缩包。
    
    - 记忆法： **x**  代表 extract（提取/解压），**z** 代表 gzip（压缩格式），**v** 代表 verbose（显示解压过程），**f** 代表 file（指定文件）。 [1]
        
- tar -czvf <压缩包名.tar.gz><目标文件夹>：把你的解答文件夹打包压缩，准备提交到服务器。 [1]
    
    - 记忆法：**c** 代表 create（创建压缩包）。 [1]
