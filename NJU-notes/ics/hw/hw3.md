## 习题 3（确定长度后缀 + 寻址方式）

| 小题 | 补全后缀 | 源操作数寻址方式 | 目的操作数寻址方式 |
|------|---------|----------------|------------------|
| (1) | `movw 8(%ebp,%ebx,4), %ax` | 存储器：基址加比例变址寻址，EA = %ebp + %ebx*4 + 8 | 寄存器寻址（%ax，16 位） |
| (2) | `movb %al, 12(%ebp)` | 寄存器寻址（%al，8 位） | 存储器：基址寻址，EA = %ebp + 12 |
| (3) | `addl (,%ebx,4), %eax` | 存储器：比例变址寻址，EA = %ebx*4 | 寄存器寻址（%eax） |
| (4) | `orb (%ebx), %dh` | 存储器：寄存器间接寻址，EA = %ebx | 寄存器寻址（%dh，8 位） |
| (5) | `pushq %rcx` | 寄存器寻址（%rcx，64 位） | 隐含为栈顶存储单元（%rsp 所指；源长 8 字节故后缀 q） |
| (6) | `movl $0xFFFF0, %eax` | 立即寻址 | 寄存器寻址（%eax） |
| (7) | `testq %rax, %rax` | 寄存器寻址（%rax，64 位） | 寄存器寻址（%rax） |
| (8) | `leal 8(%ebx,%esi), %eax` | 形式上为存储器操作数：基址加变址寻址（S=1 非比例），lea 不访问存储器，传送 EA = %ebx + %esi + 8 本身 | 寄存器寻址（%eax） |

判定要点：有寄存器操作数时后缀由寄存器宽度决定（b/w/l/q = 1/2/4/8 字节）；`$` 开头为立即寻址；`D(Rb,Ri,S)` 通用式 EA = Rb + Ri*S + D，按出场成分命名。

## 习题 4（错误诊断，原文以教材为准：后缀均为 l，(5) 为 (%dl)）

| 小题 | 错误诊断 | 合法改法示例 |
|------|---------|------------|
| (1) `movl 0xFF, (%eax)` | 立即数缺 `$` 前缀，0xFF 被解释为直接寻址的存储器操作数，与目的 (%eax) 构成两个存储器操作数；mov 不允许两者同时为存储器操作数 | `movl $0xFF, (%eax)` |
| (2) `movb %ax, 12(%ebp)` | 后缀 b（1 字节）与源寄存器 %ax（2 字节）宽度不匹配 | `movw %ax, 12(%ebp)` |
| (3) `addl %ecx, $0xF0` | 目的操作数为立即数；立即数不能作目的（运算结果无法写回） | `addl $0xF0, %ecx`（交换两操作数） |
| (4) `orw $0xFFFF0, (%ebx)` | 立即数 0xFFFF0 为 20 位，超出 w（16 位）可表示范围 | `orl $0xFFFF0, (%ebx)` |
| (5) `addb $0xF8, (%dl)` | (%dl) 为寄存器间接寻址的存储器操作数，但基址寄存器 %dl 仅 8 位，无法容纳 32 位有效地址 | `addb $0xF8, (%edx)` |
| (6) `movl %bx, %eax` | 源寄存器 %bx（16 位）与后缀 l（32 位）宽度不匹配 | `movl %ebx, %eax` 或 `movw %bx, %ax` |
| (7) `andl %esi, %esx` | 不存在名为 %esx 的寄存器 | `andl %esi, %edx` |
| (8) `movq 8(%ebp, , 4), %rax` | 有比例因子 4 却未给出变址寄存器；比例因子必须与变址寄存器连用 | `movq 8(%ebp, %eax, 4), %rax` 或 `movq 8(%ebp), %rax` |
| (9) `leaq 20(%rdi, %rsi), %eax` | 后缀 q（8 字节）与目的寄存器 %eax（4 字节）宽度不匹配；lea 目的须为与后缀等宽的寄存器 | `leaq 20(%rdi, %rsi), %rax` |

## 习题 5（IA-32 类型转换；x 按宽度在 AL/AX/EAX，ptr 在 EDX，目的是 (%edx)）

| src_type | dst_type | 机器级表示（AT&T） | 说明 |
|----------|----------|-------------------|------|
| char | int | `movsbl %al, %eax` + `movl %eax, (%edx)` | 加宽 + 源带符号 → 符号扩展 |
| int | char | `movb %al, (%edx)` | 截断免费：直接取 %eax 低 8 位 %al 存储 |
| int | unsigned | `movl %eax, (%edx)` | 等宽：位模式不变，仅解读方式变 |
| short | int | `movswl %ax, %eax` + `movl %eax, (%edx)` | 加宽 + 源带符号 → 符号扩展 |
| unsigned char | unsigned | `movzbl %al, %eax` + `movl %eax, (%edx)` | 加宽 + 源无符号 → 零扩展 |
| char | unsigned | `movsbl %al, %eax` + `movl %eax, (%edx)` | 扩展方式由源决定：char 带符号 → 符号扩展；与第 1 行指令完全相同 |
| int | int | `movl %eax, (%edx)` | 等宽：直接存储 |

决策规则：① dst 更宽 → 扩展，选 movs（源带符号）或 movz（源无符号），**与 dst 的符号性无关**；② dst 更窄 → 截断，用窄后缀取低位子寄存器，一步到位；③ 等宽 → 位模式不变，直接等宽 mov。

## 习题 7（指令执行与标志位；各小题独立执行，均以表 3.12 初值为准）

| 小题 | 计算过程 | 改变结果 | 四标志 |
|------|---------|---------|--------|
| (1) `addl (%eax), %edx` | EA=0x08049300，`0x00000080 + 0xfffffff0 = 0x1_00000070` 截断 | EDX：`0x00000080 → 0x00000070` | OF=0（异号相加不溢出）SF=0 ZF=0 CF=1 |
| (2) `subl (%eax,%ebx), %ecx` | EA=0x08049300+0x100=0x08049400，`0x10 − 0x80000008 = 0x80000008` | ECX：`0x00000010 → 0x80000008` | OF=1（正减负得负）SF=1 ZF=0 CF=1（无符号借位） |
| (3) `orw 4(%eax,%ecx,8), %bx` | EA=0x08049300+0x10×8+4=0x08049384；小端取 word=0xff00；`0xff00 or 0x0100 = 0xff00` | EBX：`0x00000100 → 0x0000ff00`（高 16 位不变） | OF=0 CF=0（逻辑运算）SF=1 ZF=0 |
| (4) `testb $0x80, %dl` | 试算 `0x80 & 0x80 = 0x80`，**不写回** | 无任何寄存器/存储单元改变，仅标志更新 | OF=0 CF=0 SF=1 ZF=0 |
| (5) `imull $32, (%eax,%edx), %ecx` | EA=0x08049300+0x80=0x08049380；`0x908f12a8 × 32 = 0x1211E25500`，低 32 位 | ECX：`0x00000010 → 0x11e25500` | CF=OF=1（乘积截断）；SF/ZF 无定义 |
| (6) `mulw %bx` | `%dx:%ax = 0x9300 × 0x0100 = 0x00930000` → dx=0x0093、ax=0x0000 | EAX：`→ 0x08040000`、EDX：`→ 0x00000093`（各保留高 16 位） | CF=OF=1（%dx≠0）；SF/ZF 无定义 |
| (7) `decw %cx` | `0x0010 − 1 = 0x000f` | ECX：`0x00000010 → 0x0000000f` | OF=0 SF=0 ZF=0；**CF 不受影响（保持原值）** |

## 习题 8（机器码反汇编；核心公式：目标 = 本指令地址 + 本指令长度 + 位移，位移小端存放、负数用补码）

**(1)** je 长 2 字节：目标 = `0x804838c + 2 + 0x08` = **0x8048396**。
call 的反汇编过程：`e8` 为 call rel32 操作码（5 字节指令），后 4 字节 `1e 00 00 00` 按小端读出位移 `0x0000001e`，目标 = 下一条指令地址 `0x804838e + 5 = 0x8048393` 加位移 = `0x8048393 + 0x1e` = **0x80483b1**。

**(2)** jb 长 2 字节，位移 `f6` 为 8 位补码 = `-0x0a`：目标 = `0x8048390 + 2 − 0x0a` = **0x8048388**。
movl 目的地址的反汇编过程：`c6` 为 mov（立即数→存储器）操作码，`05` 为 ModR/M 字节（指明目的采用直接寻址、地址随后），其后 4 字节 `00 a8 04 08` 为小端存放的直接地址，逆转得 **0x0804a800**；末字节 `01` 为 8 位立即数（源操作数）。

**(3)** jle 长 2 字节，设其地址为 x：`x + 2 + 0x16 = 0x80492e0`，解得 **jle 地址 = 0x80492c8**；mov 紧随其后：**mov 地址 = 0x80492ca**。

**(4)** jmp 长 5 字节（`e9` + rel32），位移小端读出 `0xffffff00`，最高位为 1 是负数，补码真值 = `-0x100`；PC = `0x8048296 + 5 = 0x804829b`（恰为下一行 sub 的地址，可自检）；目标 = `0x804829b − 0x100` = **0x804819b**。

## 习题 10（x86-64 类型转换；x 在 AL/AX/EAX/RAX，ptr 在 RDX，目的是 (%rdx)）

| src_type | dst_type | 汇编指令（AT&T） | 说明 |
|----------|----------|-----------------|------|
| char | long | `movsbq %al, %rax` + `movq %rax, (%rdx)` | 加宽 + 源带符号 → 符号扩展到 64 位 |
| int | char | `movb %al, (%rdx)` | 截断免费：取 %eax 低 8 位一步存入 |
| int | unsigned long | `movslq %eax, %rax` + `movq %rax, (%rdx)` | 扩展方式由源决定：int 带符号 → movslq 符号扩展 |
| short | int | `movswl %ax, %eax` + `movl %eax, (%rdx)` | 与题 5 相同；目的仍 32 位，ptr 在 RDX 故存 (%rdx) |
| unsigned char | unsigned | `movzbl %al, %eax` + `movl %eax, (%rdx)` | 零扩展；目的 32 位故仍用 l |
| char | unsigned long | `movsbq %al, %rax` + `movq %rax, (%rdx)` | 陷阱行：目的无符号但源 char 带符号 → 符号扩展；与第 1 行相同 |
| unsigned long | int | `movl %eax, (%rdx)` | 64→32 截断免费：取 %rax 低 32 位 %eax 直接存储 |

x86-64 要点：long/unsigned long（LP64）= 8 字节 → `q` 后缀 + 64 位寄存器；movs/z 家族扩容 movsbq/movswq/movslq/movzbq/movzwq；**不存在 movzlq**——写 %eax 自动零扩展 %rax 高 32 位，`movl %eax, %eax` 即等价。
