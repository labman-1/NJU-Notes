# 1.使用`hexdump`命令查看测试用例的.img文件，所显示的.img文件的内容对应模拟内存的哪一个部分？指令在机器中表示的形式是什么？

`load_image(image_path, LOAD_OFF)` 把 img 拷到模拟内存的 **`LOAD_OFF = 0x30000`** 处，`init_cpu()` 把 EIP 初始化为 **`INIT_EIP = 0x30000`**。指令在机器中表示的形式是二进制序列。

# 2. 如果去掉`instr_execute_2op()`函数前面的`static`关键字会发生什么情况？为什么？
去掉 static 后**编译能过、链接会出问题**。这是因为static限制函数的作用域在本文件内，去掉之后，由于每个 .c 是独立编译的翻译单元，编译时互相看不见；到链接器合并符号表时才发现十几个 `instr_execute_2op`定义冲突。

# 3. 为什么`test-float`会`fail`？以后在写和浮点数相关的程序的时候要注意什么？
test-float 跑的 x87 指令在 NEMU 里是**简化模拟**（`x87.c` 用 32 位近似模拟真机 80 位精度的 x87 栈），与参考实现有微小误差，在运算链条中，误差不断积累，最终 `nemu_assert(结果 == 期望)` 不过 → HIT BAD TRAP。
以后在比较浮点数时，正确的比较方法应该是：不用特定“函数”，要用 fabs(a-b) < epsilon 的容差判断，因为浮点表示和运算都有精度损失。
