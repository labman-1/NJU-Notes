在NEMU中，我们将存储器体系结果划分为寄存器、高速缓存（cache）、主存储器（RAM）、辅助存储器（硬盘）这四个层次，这四个层次的关系基本是越来越慢，越来越便宜（存储量自然越来越大），离CPU核心越来越远。
![[数据的存储_202608301843.png]]

| 寄存器   | 可以先这样记        | 常见用途                                     |
| ----- | ------------- | ---------------------------------------- |
| `RAX` | 计算结果、返回值      | 保存算术结果，函数通常通过它返回整数或指针                    |
| `EAX` | `RAX` 的低 32 位 | 32 位操作数、32 位返回值等                         |
| `RDI` | 第一个参数         | Linux x86-64 常用调用约定中，第一个整数或指针参数通常放这里     |
| `RSI` | 第二个参数         | 同一调用约定中，第二个整数或指针参数通常放这里                  |
| `RSP` | 栈顶的位置         | 保存当前栈指针，配合 `call`、`ret`、`push`、`pop` 等操作 |
| `RIP` | 当前执行位置        | 指示处理器接下来要执行的指令位置                         |
在x86-64中，向32位寄存器写入新值，会自动把对应64位寄存器的高32位清零。

| 寄存器 | 全称 | 身份 | 记忆 |
| --- | --- | --- | --- |
| eax | accumulator | 累加器，算术默认主角、返回值 | a=accumulate |
| ecx | counter | 循环计数（jecxz 就是查它） | c=count |
| edx | data | 数据副手，乘除法存高位 | d=data |
| ebx | base | 通用 + 寻址基址 | b=base |
| esp | stack pointer | 栈顶指针——专用，别挪用 | sp=stack pointer |
| ebp | base pointer | 栈帧基址锚——局部变量的参照系 | bp=base pointer |
| esi/edi | source/destination index | 字符串指令的源/目的指针 | i=index |
