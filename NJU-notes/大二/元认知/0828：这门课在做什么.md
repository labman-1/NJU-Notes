# 0828：这门课在做什么
**智能时代认知科学：元认知理论与实践应用**

### 智能时代的认知困惑
1. 如果写作、编程这些原本需要不断学习训练才能掌握的技能，AI可以做的比我们大多数人类都更好，那么我们还应该学习什么？有没有一种可能，我们学习的内容，在不久的将来，又被AI取代
2. 我看着AI在那里工作，有一种插不上手的无力感，纵使AI一晚上输出了看起来还行还能用的东西，但是我内心那种什么都没有获得的空虚感却愈发强烈
3. AI有一种顺从感，它被调教的迎合你的需求。看着它的输出，判断它输出是否正确或者是否完备，是一件非常麻烦的事情，但是我什么都不懂，似乎我只能选择相信它
4. AI可以用极短的时间，给我们搓出大概能用的东西，但是这玩意从能用到好用，到封装成产品移交给其他人使用，所需要耗费的时间和Token会暴增，面对一堆已经能用的东西，每往前走一小步，代价可能都是巨大的，它真的会把对的改成错的，关键是，从一开始我们就丧失了对项目细节的掌控权

其他抽象的感受就先不赘述了，大家有补充的话，可以后面跟帖补充

### 我们希望看到自己的成长
> 大脑对看到成长的反馈，比对最终成功的反馈更加敏感和持久
>

所以即使在AI时代，我们也希望看到自己的成长

某公司做过一项粗略的调研，它问自己的员工，在使用生成式AI参与工作后，评估自己的创造力是否有增长，调研结果是26%的人表示有所提升

我们暂时先不去评估这个调研的准确性，但是这个调研结果，有一件事是确定的： 有些人能从AI受益，而另一些却不能

为什么会这样，这是一个有趣且值得深究的问题

### 元认知的重要性
> 当一个人拥有足够的认知资源时，他们能够产生更多创造性想法
>

基于上述定理，认知资源在创造过程中，包含两个关键的要素

+ 信息与知识的储备
+ 调整工作学习方法和任务的机会

使用AI可以通过两种关键方式增加人类的认知资源

+ 拓展知识边界：AI能提供大量信息，这扩大了使用者的知识基础，使他们能够整合跨领域的见解
+ 释放思维能力：AI替代人类完成文本总结、数据管理和内容起草等任务时，减轻了使用者的认知负担，使他们能够将宝贵的认知资源聚焦在复杂问题的解决上

然而AI工具并不能保证个体能够获取创造力所需的认知资源。在24-25级的学生实践经验中，我们发现个体在利用AI获取认知资源的能力上存在显著差异。 一个关键的区别因素在于个体的元认知能力：即在完成任务时积极监控自身思维的能力

这种持续的反思使优秀的个体更清楚自己的知识差距、任务的要求以及自身的精神状态。因此，他们能更好地理解自己需要什么信息，以及何时转换思路或休息以打破固定思维模式并恢复认知能力。相比之下，元认知能力较低的个体更有可能接受AI给出的第一个答案，依赖默认输出，并且不会去检查AI的建议是否准确或相关。结果是，元认知能力较强的人更有能力利用AI工具获取激发创造力的认知资源，而元认知技能较弱的人则从AI中获得很少的创造力提升

> 因此，在智能时代，更为重要的不再是静态的知识内容本身，而是主动驾驭和管理知识的元认知知识
>

### 元认知是啥

### 元认知增长的困境
元认知监控依赖前额叶皮层，这是大脑最耗能、容量最有限的部分。当你专注做一道数学题时，和当你抽身出来思考我为什么卡住了相比，大脑需要抑制当前思考的主任务，同时激活前额叶皮层，这种不断切换的思考状态，会天然导致认知负载高

当你原有的思维框架无法解释新错误时，会发生认知失衡的现象。只有在这种时刻，你才会被迫放弃旧有的评判标准（比如只要做对或者完成就行），跳到更高的评判标准（比如能给别人讲通或者消耗更少的认知资源）。这个跃迁现象不是匀速积累，而是突变式的

元认知的发展遵循递归规律，同一个错误（比如计算粗心），在低层级元认知看来是只要下次细心一些就能变的更好，在高层级元认知看来是别的可能：

+ 可能是草稿纸过于潦草：誊抄时遗漏正负号或者草稿上书写不规范，自己认错
+ 可能是速度和正确的博弈：懒的按部就班计算会使用心算提速，正确率随之下降
+ 可能是注意力无法长时间集中：做题中间思路被外部环境打断后，再恢复时出现错误
+ 可能是思维惯性：看到自己熟悉的，就默认使用惯性的套路，结果其实有变化
+ 可能是疲惫：平时训练和考试不一样，很难在平时调动足够的认知资源来不断进行大量重复训练

所以，成长不是画圈，而是上升的弹簧，每次都可能绕回原点，回到当初的那个问题，但是当你站在了更高的认知层级，你就能看到了原来根本看不见的因果链

心理学区分陈述性元认知（懂方法）和程序性元认知（自动启动），绝大多数人仅仅停留在前者

真正的元认知增长，必须发生在做的过程，而非事后写总结时悟到。因为只有当你身处高压、时间紧迫、情绪波动的真实任务中，你大脑的错误监测机制才能与现实反馈形成闭环。如果你只在脑内演练，一旦进入实战，情绪脑杏仁核将接管任务，前额叶开始离线，你所谓的知就会失效。只有把监控动作嵌入行为程序，直到形成大脑记忆般的觉察，才算真正完成元认知的增长。

> 知道那么多道理，依然过不好一生
>

### 课程的共识
原则性的共识

1. 内驱式学习：课程不会强制要求什么，那样会增加很多额外的管理性成本，但是会记录大家的表现
2. 自主性学习：提升元认知总要有个起点，这个起点应该努力的成为自主性的选择
3. 过程性学习：不要憋大招，憋出成果也不代表你就厉害了，请努力暴露你的思维过程，分布式的小频次的反馈，不要抗拒输出
4. 碎片化学习：当你努力实现A目标的时候，很可能因为认知储备不够，导致卡在中间，不妨将你的目标迁移为BCDEF，这种现象，并不代表自己不够优秀和努力，它更符合客观认知规律
5. 知行合一：课程作业就是行、课程复盘讨论是提升知

如果还有其他问题，后续再讨论补充

### 具体要求
关于内驱：不想耗费过多的精力在课程管理上，当然也承认外部环境、时代让现在的孩子在学习这件事上存在各种现象（如DDL驱动等），如果你觉得课程的要求很高，自己的精力跟不上，请思考课程的目标后决定是否要继续坚持，如果你想要坚持，那请使用元认知的方式思考为什么自己的精力跟不上从而无法实现内驱式学习，并将目标迁移为调整自己的认知资源分配

关于起点：课程不设置固定的任务，因为不合理，所以你们可以将起点设置为你们原本就打算或必须要去做的事情（比如其他课程的大作业），本课程关心的是你在解决具体问题的时候，思维过程是什么，并从中找到问题，有意识的加以训练改进，所以对起点目标最终是否能够实现，并无特定的要求

关于认知水平差异：差异会带来负面的情感体验，但这是无法避免的客观现象。课程会有调节ZPD的设计，但是无法保证每一次线下反馈，都能将ZPD的差异控制在一定范围内。相反，可能有时候，反而需要认知差异过大的碰撞，才能突破固有的认知惯性。请努力克服情绪带来的负面体验，坚持将学习的节奏控制在自己的手里，主动的去寻求突破

### 作业批改
作业批改的几点想法：

1. 不关注最终成果
2. 大家都提了什么需求
3. 设计的时候，大家采用了什么样的策略，思维是什么样子的
4. 遇到了哪些困难，等待突破
5. 课程、作业的情绪状态如何
6. 如果从元认知视角回看这件事，在和其他同学的思维层面碰撞之后，每个人都有哪些可以优化改进的空间

我们来把AI的CoT和人类思维进行一下简单的总结对比，然后再去看一看大家的作业

#### Ai的COT
**Ai目前提升质量的思路，就是**** 把隐性的计算过程转化为显式、可分解、可检查的推理序列，通过增加推理计算量来提升答案质量 **

输出推理过程： 问题->推理步骤->答案

 通过“让我们一步步思考”或类似Prompt，让模型自己展开推理

 让模型对同一问题生成多条推理路径，最后选最一致的答案

 不只沿一条链推理，而是生成多个候选步骤，形成树或图结构，允许回溯、分支探索

 模型交替进行：思考->调用工具->观察结果->继续思考

 把复杂任务拆成可管理的子任务，如：先计划->再执行

 通过强化学习训练模型生成更长的内部推理链

#### 人类在解决问题时：
+ 穷尽所有可能
+ 试错：尝试不同方案，对比后从错误中学习
+ 优化：比较当前的状态与目标之间的差距，逐步缩小差距
+ 逆向：从目标倒推步骤，经常用于解决问题之前的规划中
+ 类比：借用类似的问题的解法
+ 分解：将大问题拆成小问题
+ 顿悟：不懂背后的原理，但是确实人类会有这种体验，而且还相当棒（多巴胺爆棚）

#### 人类 在推理时：
+ 演绎：从一般性的规则中推导出具体的结论，有逻辑支撑
+ 归纳：从具体的事件中概括出一般性的规律
+ 溯因：根据结果推测假设最可能的原因
+ 概率：基于先验经验和新的证据，调整对事件发生的概率预期（xs，往往是错的）

#### 人类 在决策时：
+ 最理性的效能决策：评估所有选择的期望效能，然后选择最优解（基本不可能做到）
+ 有限理性原则：选择足够好的选项，心理能接受就行
+ 根据事物和可参照的范例之间的相似度来判断
+ 根据唤醒回忆的难易程度来判断事件的发生频率从而预估其重要性
+ 锚定效应：先接触的，会形成一个锚点，影响决策
+ 情绪：根据情绪来进行决策（非理性但是经常发生且可能在潜意识层有重要的影响）
+ 直觉：大脑的系统1在系统2被激活前就做出了判断，可以认为是一种模式识别的自动化过程

#### 人类 一些人类有意识进行调整的举措和策略：
发散性思维： 尽可能多、尽可能独特地产生想法，追求数量与多样性

 收敛思维：从众多可能中筛选、评估并聚焦于最优方案

 类比与隐喻： 跨领域建立联系，用熟悉的事物理解陌生的事物

 升维思维： 跳出常规框架，从更高维的角度审视问题

 孵化：暂时不管，以后再说

#### 人类元认知：
+ 计划
+ 监控
+ 评估
+ 校准
+ 认知资源自主分配
+ 情绪评估与响应

#### 人类 学习和记忆过程：
 将新信息与已有知识体系进行链接，加深理解

 把信息分类、排序、建立层级或图式，便于提取

 分散练习时间，增强长期记忆

 主动回忆与唤醒，加深知识在边界的理解，从而达到真正理解

 刻意练习（如做卷子或参加比赛）在挑战性任务中专注改进弱点，获得针对性反馈

#### 人类社会认知：
换位思考、协作、说服他人、模仿

我想想怎么总结一下哈，人类的思考还真是复杂
双系统运作，两个系统相互配合和竞争认知资源的主导地位。我们进行策略选取时，需要考虑任务、环境、情绪、动机等多种因素，且因为认知资源有限，只可能采用有限理性的模式。情绪既是影响思考的干扰因素，也是人类进行价值判断和决策的重要的信息来源。人具有社会性，人类的思考决策过程也具备社会性，人类可以通过元认知对自身的思维进行反思、监控和修正（**这一点AI目前做不到这么高效**）
