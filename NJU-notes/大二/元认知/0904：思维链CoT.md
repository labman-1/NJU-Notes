元认知科学的最重要的一个点就是需要我们对自己的思维过程有意识的进行观察评估反馈

《思考，快与慢》这本书基于大量的实验，通过系统1与系统2这个简单的概念描述，解释了我们人类在思维上的一些常见的现象，并且给出了基于两套系统的一种合理性解释。客观的说，它不是基于脑神经科学的视角分析人脑工作的模式，但是系统1和系统2的概念很容易被我们理解和接受，用于解释日常生活学习工作中的出现的各种现象，所以这本书的观点和结论，需要我们不断反复拿出来重温，并以此为依据来指导反馈未来我们的思维过程

### 长链思维与短链思维

**Q：如果你负责筹备一个会议，你该怎么做**

会务安排

以会议为例，在长链思维的结构中，会议筹备的事情、参会人、会议目标这些元素像一张网一样交织在一起

比如对于参会的你们来说，如果你想要借机会认识学长，提前了解未来工作的环境、状态，那么可能你需要

+ 早期聚焦学长的基本介绍，他在哪里工作、什么岗位、主要研究/工作内容是啥
+ 然后在嘉宾对接的环节，要主动报名对接
+ 在圆桌讨论环节，可以准备一些问题
+ 安排好时间，让自己能够参加学长的讲座
+ 关注学长是否参加会后活动，如果参加，可以考虑一起参与互动，增加熟悉感

对于组织会议的我来说，我需要考虑：

+ 会议定在什么时间，才能让嘉宾更加方便，参与意愿更高
+ 会议的主要目标如何实现
+ 怎么和嘉宾敲定讲座内容，以及时间安排
+ 会议志愿者如何分工，如何让所有人知道自己负责的工作和其他人之间的关系
+ 如果出现特殊情况，大家如何才能知道该找谁解决，避免所有事情集中在少数人手上，导致堵塞
+ 会议费用的金额和用途限制，如何让所有人都能遵照执行
+ ....

我们抽象的看一下上述模型，如果将会议最简化，大概就是邀请一个嘉宾来分享

但是一旦嘉宾人数超过一定数量，参会人数超过一定数量，组织会议需要考虑的事情就会急剧增加

系统的复杂度，也就是思考的链条会变得越来越长

:::info
短链思维：通常是我们熟悉、确定知道结果的一种思维模式，在思考的链路上，节点数量较少或者节点模式固定，不会有太多变化。短链思维是系统1的自然产物，大脑在使用短链思维的时候，能耗较低。同时，大脑在调用系统2工作后，其结论可以自然的过渡到系统1，从而形成新的短链思维模式

长链思维：当面对的任务具备较多且变化的节点时，长链思维就不可避免的产生了。梳理清楚链路上各节点的相互关系是一件非常耗能和复杂的事情，长链思维不是大脑的默认选项，需要长期的刺激才能更好的唤醒调用长链思维

:::

### 思维链的收益与代价
预习的视频的观点，AI在系统1的表现上，随着参数量的增加，其效果和性能显著跟随增加，人脑显然无法抗衡

AI在系统2任务上，采用思维链技术，引导AI突破“平坦缩放曲线”瓶颈

CoT、Zero-Shot CoT、Auto CoT、ToT、Self-Consistency这些概念都可以认为是一种策略

AI在训练阶段，大量使用深度强化学习算法，从结果来看，模型的能力越来越强

那么请大家思考，代价是什么？

1. 生成过程中的时间开销和成本开销
2. 链式思维的介入、判定及错误累积
3. 人类策略的加持，在更宏观尺度下看，究竟是对还是错《The Bitter Lesson》
4. Vibe Coding的启示，收益陷阱
5. AI是否剥夺了人类的思维能力锻炼

#### 关于困难
一部分人没有看到Token的通知，这个反而会引发我的思考

事实上这种通知消息模式是逐渐探索出来的，在一个地方更新通知内容，在主要社交工具微信上发布群公告，这种模式已经尽可能的减少消息源的数量，降低注意力消耗了

但是，这也只是一种一厢情愿的做法，很多时候，发布消息的人会觉得消息已经发布了，但是作为消息的接收方，这种信息还是存在不对称的可能，需要一个约定上的磨合，而这种磨合本身也会消耗认知资源，如果大家最近很忙，就会遗漏这种信息的发布模式。那么有没有更好的对齐信息的模式呢？或者当前模式需要在什么点上加强一下，会有更好的效果？

细节性的困难就不说了，AI加持下应该可以克服，有趣的是有相当多的同学在认知和情绪上隐隐的表达出了困难

+ 看别人的文档，不自觉的对比自己，真的会有压力的

+ 项目进展不顺利，或者过度耗时耗认知资源之后，逐渐开始“暴躁”

其实我感觉最大的困难，还是在于怎么把所想“知”和我们所做“行”结合起来
