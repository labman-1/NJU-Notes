### 什么是兴趣
在认知科学领域，兴趣可以理解为你和某个对象之间的一种关系

这个关系是不断变化的，它可以被触发、被维持、被发展，也可能会被掐断、暂时性终止、永久性消失

#### 兴趣的两个成分：情感+认知
 Person-object theory of interest（Krapp）

 人-客体关系理论将兴趣拆解成两个不可或缺部分

| **类别** | **含义** | **通俗说法** |
| :---: | :---: | :---: |
| **情感性价值**（feeling-related valence） | 做这件事时的积极情绪体验：愉悦、投入、被吸引 | "我喜欢它" |
| **价值性认知**（value-related valence） | 认定这个对象对个人有意义、重要、值得投入 | "我觉得它重要" |

+ 只有喜欢没有觉得重要：是**娱乐**，不是兴趣
+ 只有觉得重要没有喜欢：是**义务**，也不是兴趣
+ 真正的个体兴趣是两者共存，所以它**既能带来快乐，也能支撑枯燥的部分**

:::color5
事实上，研究表明，兴趣还和我们现有的认知资源高度相关：你对某个领域知道得越多，兴趣越容易维持，因为新的输入能耦合到已有知识体系上，所以知道的越多越有兴趣、越有兴趣知道的越多（正反馈形成）

:::

#### 个体兴趣与情境兴趣
Hidi & Baird (1986) 《Interestingness: A Neglected Variable in Discourse Processing》

| | **情境兴趣（situational interest）** | **个体兴趣（individual interest）** |
| :---: | :---: | :---: |
| 定义 | 由特定环境、任务或文本特征引起的即时性、短暂性情绪反应 | 个体长期指向特定主题、领域或活动的稳定心理倾向 |
| 归属 | 环境/事物的属性 | 人的相对稳定的倾向 |
| 持续 | 短暂，随情境消失 | 长期，跨情境 |
| 来源 | 新颖性、悬念、社交、动手、与生活的关联 | 反复的积极经验 + 知识积累 + 价值认同 |
| 举例 | 一节设计得好的课让人抬起了头 | 一个人持续十年关注天体物理 |
| 教学抓手 | 教师可以直接设计 | 教师只能"创造条件"，不能直接给 |

:::color5
情境兴趣不是个体兴趣，但它可以是个体兴趣的入口。一节精彩的课、一次偶然的体验能触发情境兴趣，却不能自动变成学生的长期兴趣。中间需要重复体验、知识积累和价值确认

:::

#### 兴趣发展四阶段
Hidi, S., & Renninger, K. A. (2006). 《The Four-Phase Model of Interest Development》

+ 触发的兴趣：被环境抓住
+ 维持的兴趣：主动想要继续
+ 萌芽的个体兴趣：愿意自己去探索更多机会
+ 成熟的个体兴趣：成为自身身份的一部分

| **阶段** | **典型表现** | **靠什么维持** | **断裂原因** |
| :---: | :---: | :---: | :---: |
| **触发的兴趣** | 注意力被抓住，"咦？" | 环境特征：新颖、意外、悬念、可动手、与他人相关 | 刺激一消失就没了；过度刺激导致疲劳 |
| **维持的兴趣** | 愿意继续投入当下的活动 | 任务的持续吸引力 + 一定的自主选择 + 能看懂（可理解性） | 难度陡增而支撑不足；被迫继续而无自主感 |
| **萌芽的个体兴趣** | 主动去查、去问、去收集；开始有偏好 | 反复的积极经验、知识增长、有人可交流、看到价值 | 缺乏进阶资源；孤独无同伴；看不到意义 |
| **成熟的个体兴趣** | 长期稳定的投入，能忍受枯燥，成为自我认同的一部分 | 内在的价值体系 + 深厚知识 + 社群 + 明确的目标感 | 环境长期敌意；重大挫败无支持；被过度外部化（如兴趣变成唯 s 一谋生手段且被评价） |

注意：

1. **阶段可以倒退**。成熟的个体兴趣也可能因长期受挫、被过度评价而萎缩。兴趣不是解锁后永久拥有的成就
2. **阶段推进需要外部支持，不是自然发生**。从触发的兴趣到维持的兴趣尤其依赖环境和他人
3. **不同阶段适用不同策略**。给处于触发的兴趣阶段的人讲深度知识是浪费，给处于成熟的个体兴趣的人做花哨导入是侮辱，用同一套手段对待不同阶段的人是灾难

:::color5
请大家就某件事想一想，自己处在哪个阶段，又最有可能向哪个阶段发展

:::

#### 兴趣的评价理论：什么会让人产生兴趣
Silvia, P. J.《Interest—the curious emotion》，《Exploring the Psychology of Interest》

把兴趣当作一种情绪，用情绪的评价理论（appraisal theory）来解释

产生兴趣需要 同时通过 两道评价：

| **评价维度** | **问题** | **结果** |
| :---: | :---: | :---: |
| **新颖性—可理解性**（novelty-comprehensibility） | 这东西新不新？我能不能看懂它？ | 只新但看不懂 → 困惑/焦虑，不是兴趣 |
| **应对潜能**（coping potential） | 我有没有能力去搞懂它？ | 觉得"我搞得定" → 兴趣；觉得"我搞不定" → 回避 |

**这个模型解释了三个日常现象**：

+ 为什么完全陌生的领域（比如给文科生突然上量子场论）不产生兴趣，只产生挫败：缺少可理解性
+ 为什么有点难但我大概能啃的材料最吸引人：两道评价都通过
+ 为什么同一份内容，A 觉得有趣、B 觉得无聊：差异不在内容本身，在A、B的知识基础、自我效能

:::color5
兴趣的个体差异，很大程度上是知识基础和效能感的差异，而不是天赋的差异。这直接支持兴趣是否可想后续阶段进行发展，所以积累尤其关键

:::

#### 好奇心（curiosity）与兴趣的关系
好奇心常被当作兴趣的代名词，但两者在学术研究中是不同的

| | **好奇心** | **兴趣** |
| :---: | :---: | :---: |
| 时间尺度 | 状态性、瞬时 | 可长期、稳定 |
| 驱动力 | "我不知道，我想知道"（信息缺口带来的剥夺感） | "我喜欢且觉得重要"（价值 + 情感） |
| 结束条件 | 缺口被填上就减弱 | 越了解越深，不一定减弱 |
| 对象 | 常常是具体问题 | 常常是整个领域/活动 |

+ 冲突—唤醒理论：新奇、意外、复杂、模糊会引发"冲突"，进而提高唤醒水平，驱动探索行为。唤醒过高则转为焦虑回避，所以存在一个最优唤醒区间
+ 信息缺口理论：好奇心是意识到我知道的和我想知道的之间存在一个缺口时产生的、类似痒痒的感觉
 - 缺口必须**被意识到**（不知道自己不知道则没有好奇）
 - 缺口必须**具体**（泛泛的我想多学点不产生好奇）
 - 缺口必须**可填**（觉得填不上将转为无助）
 - 想产生好奇，先不要增加信息量，而要制造一个具体的、看得见边界的缺口。提问、悬念、预测+揭晓、你以为…其实…，这些都是缺口制造的方法
+ 知识水平与好奇心的倒U关系：对一个话题一无所知的人不好奇，已经是专家的人对基础问题也不好奇，好奇心在中等熟悉度处最强
 - 为什么入门课容易无聊（缺口太模糊）和高级课容易劝退（缺口填不上），而知道一点但没打通的中间地带最迷人
 - 为什么跨界往往最能点燃好奇，你熟悉A领域，但是在B领域是新手，这种交界处的缺口密度最高
 - 兴趣是想要知道，而想要知道依赖于已经知道一些

:::color5
短视频产品正是这套机制的工业化应用！算法持续制造微小、具体、极易填补的缺口，让人处在永不知足的好奇循环里。但是，好奇 ≠ 学习 ≠ 兴趣。缺口填得快、填得浅，不会推进到兴趣发展的后两个阶段

:::

#### 兴趣对认知与学习的实际效应
兴趣（尤其个体兴趣）与以下结果稳定正相关：

+ **加工深度**：更倾向使用深层策略（组织、精加工、批判性处理），而非表层记忆
+ **坚持性**：在困难、枯燥、无外部奖励时仍持续投入
+ **自我调节**：更少需要外部监督，更多主动设定目标与监控
+ **学业成就**：兴趣与学习成绩存在正相关，且与文本难度、任务类型有调节关系
+ **情绪与幸福感**：与个人相关的任务提升自主性动机与活力

#### 好奇状态提升记忆
读了一个有趣的实验

高好奇状态下，无关的附带材料（实验使用了中性的人脸）记忆也更好（比如某个水群很厉害的xdx的照片，一下子就能记住），这种效应在即时测验和1天以上的延迟测验上都存在。研究涉及脑区：黑质/腹侧被盖区与伏隔核，多巴胺通路（看不懂，算了不那么较真，你说的都对）

:::color5
这个实验给出了一个反直觉、可操作的结论：学习内容的排序本身就是变量。把必须记住的枯燥材料，安排在高好奇的时刻（比如刚被一个好问题勾住之后），记忆效果更好 —— 哪怕它和那个问题无关

:::

#### 有害的诱惑性细节
Harp S. F.& Mayer R. E.《How seductive details do their damage: A theory of cognitive interest in science learning》

这篇文章中提到了另一个实验：在一堂说明性科学课上（解释闪电成因）插入有趣但与教学目标无关的故事/图片/趣闻（Seductive Details），结果被试者的记忆与迁移解题表现下降

作者认为这种现象背后的原因并不是Seductive Details抢占了有限的认知资源，他给出的解释是诱人细节激活了不恰当的模式（priming inappropriate schemas）：读到闪电伤人的趣闻会唤醒下雨很危险这类已有框架，被试者随后带着这个错误框架去组织正文的因果链，于是理解就跑偏了

论文同时给出了另两个结论：

+ 补救措施无效：划线强调、预先给出教学目标、插入信号提示，都无法消除损害
+ 位置效应：诱人细节放在课文开头损害更大，放在结尾损害较小

:::color5
要让学生感兴趣，就把课讲得好玩、多塞段子就行了，这是错误的，真正有效的不是加料，而是让核心内容本身与学生的目标、身份、生活产生关联。这同时也解释了为什么一套趣味化教学设计不可能对全班同时有效，因为班上学生的目标、身份、生活具有多元各异性，也就是从兴趣角度出发：相关性 > 趣味性

:::

#### 总结
| 流行说法 | 文献立场 |
| :---: | :---: |
| 兴趣是天生的，要去发现 | ❌ 反驳。兴趣是可发展的关系，有明确阶段和外部支持条件 |
| 找到兴趣之后就一帆风顺了 | ❌ 反驳。持此信念者在遇到困难时更快放弃 |
| 有兴趣就不需要努力 | ❌ 反驳。成熟兴趣恰恰表现为愿意为它承受枯燥与挫折；四阶段模型中的三、四阶段的特征就包含耐受性 |
| 兴趣 = 觉得好玩 | ⚠️ 不完整。兴趣 = 情感价值 + 认知价值+ 知识储备 |

1. **兴趣不是万能的**。它可以解释是否愿意投入，但是不能决定能不能做好。技能获得仍依赖刻意练习、反馈、时间投入，不能用兴趣替代努力
2. **我觉得应该考虑文化的适应性**。这些研究文献绝大多数来自西方，兴趣的自我报告、自主性需求的表达方式在东亚教育情境下可能不同。咱中国人很可能在某些点上具备不同的特征
3. **评测其实挺困难**。个体兴趣多用自评问卷，存在社会赞许与自我认知偏差；情境兴趣的即时测量与长期追踪之间难以打通，现在还没有一套很客观的被大众认可的量化方法

### 什么是内驱
内驱力是我们通俗性的说法，在认知科学领域，内驱力对应两个主要概念：intrinsic motivation（内在动机）& autonomous motivation（自主性动机），关于内驱力的研究，不关注动力的大小，更关注动力的来源（这种动力从哪里来，由什么来维持）

**内在动机**：因为活动本身有趣、令人愉悦、令人满足而去做它

**外在动机**：为了获得活动之外的结果（奖励、避免惩罚、赢得认可、达成目标）而去做它

| **内在动机的依赖因素** | **定义** | **满足时的体验** | **受挫时的体验** |
| :---: | :---: | :---: | :---: |
| **自主（autonomy）** | 我的行为出于我自己的意愿和认同，不是被逼迫、被操控 | 我选择做这件事 | 我不得不做
抵触、敷衍 |
| **胜任（competence）** | 我能有效应对环境，能看到自己在变强 | 我做得成、我在进步 | 我怎么都不行
放弃 |
| **归属（relatedness）** | 我被在意的人接纳、关心、有联结 | 有人和我一起、有人在乎 | 我一个人、没人懂
疏离 |

#### 奖励为什么会帮倒忙
Deci & Ryan, 《Intrinsic Motivation and Self-Determination in Human Behavior》

任何一个外部事件，都会被人解读为两类信息之一

| **解读** | **效果** | **例子** |
| :---: | :---: | :---: |
| **控制性（controlling）** | 削弱自主感
削弱内在动机 | 做完作业玩手机；考到第一名换手机；计件奖金；截止日威胁；监视 |
| **信息性（informational）** | 增强胜任感
增强内在动机 | 具体的、非比较性的正反馈；你这段分析很清楚，因为… |

:::color5
同一个事件，对不同的人、在不同的措辞下，可以是控制性的，也可以是信息性的。问题的核心不在于要不要给奖励，而在于它被体验为控制还是能力反馈

:::

#### 动机连续体（Motivation Continuum）
将人类行为的动机按自我决定程度的高低和自主性，从低到高排列为一个连续的谱系，突破了以往将动机简单二分为内在和外来的局限

| **类型** | **驱动语** | **例子** | **质量** |
| :---: | :---: | :---: | :---: |
| 无动机 | 我不知道为什么要做 | 彻底躺平 | 最差 |
| 外部调节 | 做了有奖，不做要罚 | 为GPA刷题、全勤奖打卡 | 低：需持续外力 |
| 内摄调节 | 不做我会内疚/丢脸 | 怕被父母失望而学习、为面子加班 | 中低：有动力但伴随焦虑、自我攻击，容易倦怠 |
| 认同调节 | 我承认这件事对我重要 | 明知枯燥仍坚持背单词，因为想出国交流 | 中高：这是最被低估的一类 |
| 整合调节 | 这就是我是谁 | 我是一名要做研究的人，所以读文献 | 高：与自我认同一致 |
| 内部动机 | 我就是喜欢 | 纯粹因好玩而钻研 | 最高：最持久、最有创造力 |

:::color5
其实教育的主要工作，不是直接唤醒内在动机，

CAC在思考，教育应该是给大家提供理由、承认感受、给出选择才对，所以反过来，内摄调节（内疚驱动、面子驱动）看起来是有驱动力的，实际是倦怠和心理健康问题的高风险来源

:::

#### 外部环境如何塑造内驱力
自主支持型环境的行为特征

+ **给出理由**：说明为什么这件事值得做，而不是只说照做
+ **提供选择**：在有意义的维度上让人选，而不是全给或全不给
+ **接纳负面感受**：用你觉得焦虑烦躁是正常的话术，而不是别抱怨，抱怨也没用的话术
+ **用邀请代替命令**："必须"、"应该" or "来试试"
+ **不给控制性反馈**：反馈针对具体行为与信息，不针对人格、 不做社会比较

:::color5
注意：选择对内在动机有正向但幅度有限的效应，且受多种因素影响，过多的选择、或从他人视角出发、被安排的选择，反而会削弱其内在动机

:::

#### 夸奖未必是对的
同样是有实验证明的

+ 被夸赞的组（人格夸赞）在随后遇到困难时，会变现的更倾向回避挑战、坚持性下降、 兴趣性下降、成绩下降，且更倾向谎报自己的分数
+ 被过程表扬的组，后续的表现则更稳定
+ 可能一旦失败就意味着我不是那么聪明的心理因素产生了负面影响
+ 可能被关注之后，担心让对方失望的情绪反而会排斥这种夸赞

:::color5
该骂骂，内驱力原本就不是提高GPA的工具，它的存在与否，决定了你这辈子的幸福感

:::

#### 总结（让AI生成了一下常见误区）
| **误区** | **观点** |
| :---: | :---: |
| 内驱力是天赋，有人有有人没有 | 它是需要满足的产物，随环境变化 |
