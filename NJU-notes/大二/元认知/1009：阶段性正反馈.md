# 1009：阶段性正反馈
### 课上安排（仙林班）
+ 集体阅读输出者的文档 5mins
+ 输出者挑选1人依据文档复述输出者的任务，如果被挑选者无法顺利的阐述，则由输出者自己补充说明 5mins
+ CAC提问题，输出者回答问题 10mins
+ 全员给出自己的意见或者建议 10mins
+ 简单总结

### 课上安排（苏州班）
+ 集体阅读两位输出者的文档 10mins（CAC可能会迟到几分钟）
+ 输出者挑选1人依据文档复述输出者的任务，如果被挑选者无法顺利的阐述，则由输出者自己补充说明 5mins
+ CAC提问题，输出者回答问题 20mins
+ 全员给出自己的意见或者建议 20mins
+ 简单总结

### 课后总结
+ 不设置DDL的效果是糟糕的
+ 三周里更新（内容和频次）基本集中在最后几天
+ 请大家估算一下在作业上投入的总时间
+ 文档普遍存在的问题
 - 写清自己的思路是一件挺难的事情
 - 好好写一篇文档非常耗时间
 - 过程性的写文档是一件需要训练的事情
+ 将自己的预期回归到客观

### 本周作业
根据课上所讲内容，按照自己规划的任务，向前推进，撰写文档阐述 实践过程、遇到的问题、对问题的思考、以及解决问题的方法

+ 实践过程允许使用AI辅助，但是文档内容 不允许 直接粘贴AI输出，尝试自行理解后输出
+ 不要怕成果推进速度慢，但是 请投入足够多的时间和精力
+ 作业 提交位置 请按课程通知公告中新的要求进行 变更
