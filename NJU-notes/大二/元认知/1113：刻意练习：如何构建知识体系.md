# 1113：刻意练习：如何构建知识体系
### 写字的故事
一个X岁的小姑娘在学习写自己的名字：**沐**

X=3时，这个字不是字，它是一堆没有意义的图像符号：一横、一竖、一撇、一捺，还有三个点

她要同时记住这些零件长什么样、谁在谁左边、谁在谁上面，才能把这个字拼出来。她的小脑袋里像摆了一张小桌子，桌子上只能放四把椅子，可这个字一下子来了七八个客人，椅子不够，客人就挤成一团。她写得很慢，写着写着就歪了

X=7时，再写自己的名字时，她会把自己的名字打包成三点水和木字旁，原来的小图片变成了小箱子，左边一个，右边一个，记起来相当方便

:::success
这就是理解的第一层秘密：工作记忆是一张很小的桌子，长时记忆是一个很大的仓库

新手为什么懵？不是他笨，是客人太多，椅子太少

专家为什么厉害？不是他脑子更大，是他早就把一堆零件打成了包，存在仓库里，用的时候一拎就出来

:::

### Embedding
定目标： 计算机怎么判断两段文字意思相近

 怎么让电脑跑得更快

+ 计算机性能优化的方法
+ 跑得更快：跑步机选购指

 猫咪不吃东西怎么办

+ 猫食欲不振的原因与对策
+ 狗狗不吃东西怎么办

** 如何让计算机比较两段文字的语义相似性，而不是字面重叠？ **

| | 是否动物 | 是否动作 |
| :---: | :---: | :---: |
| 猫 | | |
| 狗 | | |
| 追 | | |
| 跑 | | |
| 老鼠 | | |
| 鸟 | | |
| 叫 | | |
| 飞 | | |
| 吃 | | |
| 鱼 | | |

猫吃鱼、狗追猫、鸟边飞边叫

每个词不再是孤立的符号，而是一组数字；数字接近的词，在**你的特征标准下（是否动物、是否动作）**是相似的。正式地说，Embedding是把对象表示为连续向量空间中的点，使得语义上相似的对象在空间中距离更近。

**数学表述相似！！！**

Embedding = 用一组数字（向量）表示一个对象，让意思相近变成数字上接近

维度 = 模型选择用来描述对象的特征的数量

起源关系：为什么不能继续用one-hot

如果我们还是使用传统的方式计算，“猫”和“狗”在数学上和“猫”和“汽车”一样远

性质关系：Embedding空间里“距离”意味着什么

> 国王 − 男人 + 女人 ≈ 女王
>
> 巴黎 − 法国 + 日本 ≈ 某个向量（东京）
>

这不是说模型真正理解了性别，而是说在训练出来的向量空间里，从男人到国王的方向，与从女人到女王的方向是平行的，**方向承载了关系**

语义相近 ⇔ 向量距离近

语义关系 ⇔ 向量方向/相对位置

那么怎么计算**距离**呢？

+ 余弦相似度
+ 点积
+ 欧式距离
