# 作业批改：苏涵瑜
> 但是抓取思维训练营出了问题，它的识别逻辑是标题里有没有“思维训练营”……改之
>

你咋改的，知道原因吗？

## 1. 完成度判定
+ 状态：已完成
+ 依据：系统完整跑通并产出实际成果——297人团队名单分组、52篇文档抓取分析、首份周报(v0.3)落盘、4场训练营抓取通告生成、反馈闭环跑通一轮（prompt迭代3版）。有详细的需求分析、搭建过程日志、最终成果汇报。

## 2. 系统需求清单
1. 发现xdx成员在"元认知"/思维层面的共性问题，与自身经验重合，为思维训练营寻找素材【亮点：从管理者视角定位需求】
2. 抓取每周初级社员发布的思维训练营内容，方便通告【亮点：自动化通告流程】
3. 团队成员分组管理——拉取名单后手动选择关注群体（xdx分组/新手社员/初级社员）【亮点：灵活的分组机制】
4. 周报聚类分析——共性问题点名典型人物+原文证据→开营建议（话题/前置任务/标题）→值得读的好文档【亮点：从问题到行动的完整链路】
5. 训练营按"举办周"而非发布时间判定【亮点：TOC日期分组+文档内活动时间校验】
6. 反馈闭环——用户评价→重读历史案例→修订prompt→记录历史【亮点：prompt自进化机制】
7. 存储策略——素材每周清理防膨胀，报告永久归档【亮点：可持续运维设计】
8. 短口令触发——本地skill，说"跑nova周四流程"即触发全流程【亮点：极低使用门槛】

## 3. 搭建思路
+ 工具选择：从OpenCode转向Codex（多人推荐），安装让豆包agent代劳。
+ 官方API优先，不爬网页；自动探测Token类型（个人Token只能读个人文档，团队Token读团队文档）。
+ 成员名单：团队接口有分页陷阱（每页不足100条仍有下一页），修正后拉到完整297人；PDF做首次分组+手动调整窗口+每周自动检测变动。
+ 文档抓取：先按"自然周+作者匹配"过滤，再拉正文，并行抓取+节流（约4请求/秒）。
+ 周报分析prompt从v0.1迭代到v0.3，每次修订有记录可追溯。
+ 做成Codex本地skill（nova-agent），短口令触发。
+ 技术栈：Codex、语雀官方API、DeepSeek、Python、Codex skill。

## 4. 技术评估：方案是否覆盖需求
| 需求 | 覆盖情况 |
| --- | --- |
| xdx共性问题发现 | ✅ 周报聚类分析，点名典型人物+证据 |
| 训练营内容抓取 | ✅ 按举办周判定，本周4场全抓到 |
| 成员分组管理 | ✅ 297人分组+手动调整+自动变动检测 |
| 周报到开营建议 | ✅ 话题/前置任务/标题三块，禁止抽象哲学题 |
| 反馈闭环 | ✅ prompt迭代3版，每次有记录 |
| 存储策略 | ✅ 素材每周清、报告归档 |
| 短口令触发 | ✅ Codex本地skill |

+ **风险/改进**：团队文档目前只有20篇（自述），数据量小可能影响聚类效果，需随时间积累验证。PDF做首次分组的方案在成员变动频繁时维护成本较高，可考虑用API直接获取成员角色信息。prompt迭代依赖人工评价，可考虑引入自动化质量评估指标。

## 5. 元认知视角评估与鼓励
+ **思维过程暴露程度**：高。搭建过程以流水账式日志呈现，真实记录了每一步的发现和调整（分页陷阱、标题关键词判定失误、文档全扒到D盘等），这种"边做边记录"的方式很好地保留了思维过程。
+ **亮点鼓励**：
 1. 从管理者实际需求出发——"为思维训练营寻找素材"+"方便通告"，不是为做系统而做系统，而是解决真实管理痛点，值得鼓励！
 2. prompt自进化机制设计得很棒——用户评价→重读历史案例→修订→记录，形成了可持续改进的闭环，这不是一次性工程而是长期运维思维。
 3. "建议必须能直接开营（禁止抽象哲学题）"——这个约束体现了对AI输出 tendencies的深刻理解，知道AI容易生成空洞建议而主动设防。
+ **可提升处**：搭建过程日志偏向碎片化记录，缺少对关键决策的系统性复盘（如"为什么选Codex而非OpenCode"只有"多人推荐"一句话）。团队文档仅20篇的限制可以更主动地分析影响。"好期待ai给我的人格画像"这个需求提到了但未跟进，可以思考这背后的自我认知需求。

## 6. 困难总结
1. **豆包配置API连接错误，给出了不存在的模型名（deepseek-code-v2）**（技术性，已解决——寻求小红书教程）
2. **团队成员名单只能扒拉到99个（API分页陷阱）**（技术性，已解决——修正分页逻辑后拉到297人）
3. **思维训练营识别逻辑有误——按标题关键词只找到2场（实际4场）**（技术性，已解决——改为按TOC日期分组+文档内活动时间校验）
4. **Codex把文档全扒到D盘，磁盘迟早爆炸**（技术性/运维类，已解决——素材每周自动清理）
5. **上次搓智能体是很久以前，生疏了**（认知性/知识差距，已解决——通过实践恢复）
6. **团队文档只有20篇，数据量小**（技术性，部分解决——"慢慢来吧"，需时间积累）
7. **prompt质量需多轮迭代**（技术性/认知性，已解决——从v0.1迭代到v0.3，有记录可追溯）
