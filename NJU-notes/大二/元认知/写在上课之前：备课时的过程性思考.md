# 写在上课之前：备课时的过程性思考
### 写给自己
一边备课一边在想一个问题：究竟是哪里来的勇气，让我把课程教改成现在这样的（被自己的胆大气笑了）

这是一门新的课，是一门我自认为的教改课程，之前组织学生进行教学、科研、实践活动的经历

有一些我认为基本原则的客观规律，需要遵循

> 人类的大脑生来不是为了聪慧，而是为了生存，智能是被逐渐训练出来的
>
> 个体的元认知水平存在显著差异，且认知的提升无法突变，是异步的、非线性的
>
> 平凡（非平庸）的人更容易感到幸福，从概率上看，我们绝大多数人，这一辈子都会是平凡的
>

有些抽象，无妨，看的懂看不懂都没关系，因为这是写给我自己看的

写在这里，是在教改过程中遇到问题和困难，需要不断回头看的

### 这门课究竟是个啥
站在学生视角去看，选这么课的初衷或许是：

+ 它的名字，元认知唉，听起来高大上的东东
+ 它的课程性质，通识课本来就少
+ 它的任课教师，你们当中不少人认识我或者从身边人听说过我
+ 它的时间段，正好我这个时间段是空的，那就报上再说

可是连我本人都没有信心说自己完全想好了这门课该怎么上，作为学生的你们更不太可能了

所以我紧急的在课程备注上加上了以下话语：

:::success
请慎重考虑

教改课程，每节课都组织全员汇报讨论

课后作业需要投入足够的时长

平时成绩占比较多

:::

别笑，我是认真的

别哭，我是冲着黑榜去的

选课之前，听一句劝，咱们彼此，还是先统一一下对这门课的认知吧

### 我在担心什么
总结下来三件事：

1. 大家的认知水平存在差异，课程教学的节奏就无法统一。虽然课程不关注速度（认知水平高低），而是关注加速度（元认知是否增长），但是具体操作层面，让认知高的孩子和认知低的孩子在一起用相同的节奏组织教学，会让双方都很困惑
2. 课程人数较多时，即使使用翻转课堂的形式，课上也没有足够的时间，让每个人都可以展示自己的思维过程并获得宝贵的反馈。大部分学生会隐藏在背后，惯性的采用被动式的方式进行学习，课程会陷入尴尬的境地
3. 课程会在平时布置大作业，不过大部分学生都习惯于DDL导向，这会导致DDL前的信息扎堆出现，加剧反馈瓶颈的生成。教师的个人精力、团体组织的时间空间保障，都会在有限的反馈窗口成为阻碍

想了很久，不得不说，这些操作层面的困难，背后指向的其实是一个根本性的矛盾：

:::warning
**传统课堂的结构本身，是一个不利于元认知增长的环境**

课堂的物理形态（统一时间、统一空间、统一节奏、教师中心反馈）恰好复刻了课程要改变的东西

强制跨维度比较、单一评价节奏、被系统裹挟，用内卷结构去教反内卷，这可是一个自我矛盾

:::

#### 认知水平差异和课堂的统一节奏
先引入一个概念ZPD：学习者独立完成任务的能力水平与在他人（教师或同伴）协助下所能达到的潜在能力水平之间的区域。

其中近侧发展区间（挑战区）是学习者独立无法完成，但在他人指导下可以完成的黄金学习区

显然，每个学生的ZPD不同，统一节奏意味着教师只能瞄准某个"平均ZPD"，结果是：

+ 认知高的学生：内容落在"已掌握区"，产生无聊感，参与动机下降
+ 认知低的学生：内容落在"挫败区"，产生习得性无助，同样退缩

两类学生的表现最终趋同——都变成被动旁观者。但原因完全不同。问题的本质不在于该如何调整节奏，而在于谁在定义节奏。当节奏被任课教师由外部统一设定时，学生的自主性就会随之被剥夺，元认知无法启动，因为它启动的前提是“我在驱动自己的学习过程”而不是“我在跟随他人的过程”

#### 课堂零输出的心理学效应
旁观者效应（Bystander Effect）：人越多，越不该我来做

+ 责任扩散（Diffusion of Responsibility）：当有其他人在场时，个人责任感会显著降低，潜意识里认为别人会去做这件事，人数越多，这种效应越明显
+ 多元无知（Pluralistic Ignorance）：当情况不明朗时，个体倾向于观察他人的反应。如果其他旁观者表现得很冷静或没有行动，个体就会认为这可能不是紧急情况，从而选择袖手旁观，这个心理机制进一步加剧了旁观者效应
+ 评价顾虑（Evaluation Apprehension）：个体担心自己的输出不够专业，或者采取行动会引来他人的负面评价或尴尬，从而选择不作为

社会惰化（Social Loafing）：群体越大，个体贡献越难被识别，投入越少

+ 责任扩散（Diffusion of Responsibility）：人越多，越难形成主体的责任感
+ 成绩不可衡量：在群体里，个人的贡献很难被精准定义和评估，这会导致惰化心理，尤其当团队里出现消极怠工行为后，为了避免损失，会自动降低自己的努力程度

评价焦虑（Evaluation Apprehension）：个体因预判自己的行为会被他人观察、评判或审视，从而产生的过分担心、紧张和不安感。尤其是这种在全班面前暴露思维过程的行为，其心理成本极高

+ 负面评价恐惧（Fear of Negative Evaluation）：害怕被他人批评、否定、嘲笑或产生不良印象
+ 正面评价恐惧（Fear of Positive Evaluation）：也会害怕获得表扬，因为担心这会抬高他人对自己的期望值，导致未来难以达标，或引发竞争压力
+ 测试与表现焦虑：在公开演讲、考试、绩效评估等明确需要打分或考核的场景中，压力会急剧攀升

通常情况下，课程上组织讨论的形式，是一种公开展示的模式，在这个模式下，尤其在人数相对较多的场景下，会触发输出这的心理防御机制，上课这种陌生环境中，输出自己的思维过程，在群体中几乎是不会自发出现的现象，需要强有力的机制保证和引导

#### 反馈的时效性与间隔效应
从认知科学的视角看问题，认知的改变是依赖实时反馈的，人类的大脑就是这么被设计的不是嘛

所以间隔效应（Spacing Effect）指出：分布式的、小频次的反馈，效果是远远优于集中式的，大规模的反馈的

如果还是依赖教师这种天然的单点反馈资源，那无论怎么设计，一个班级的学生个性化反馈都将成为瓶颈与灾难

在缺乏过程性即时反馈的系统中，只有DDL提供了明确的外部压力信号

大学学习相较于高中阶段的习题刺激，很难形成即时反馈的过程性学习，这对学生来说等同于付出没有目标和自我校验的标尺，只有少数人有意识的自主去构建这个实时反馈的刺激，那么推迟到不得不做就成为了大多数人的选择

### 我在期待什么
理想化的，真心希望实现：

:::color5
 发展学生批判性思维与问题解决能力

 培养学生合作精神与领导能力

 培育学生强烈的家国情怀与社会责任感

 培养学生探究精神与创新创造能力

 培养学生有效沟通的能力

 提升学生数字素养

:::

 咱还是现实点：

+ 不能也不该每个人做同一件事，而是基于个人自己的起点，按照自己的认知起点开始去做，课程的任务是带领所有人凝视大家的思维过程
+ 构建多种反馈系统，不能再依靠教师单点的反馈，要从自我反馈开始，到引入AI的反馈、同伴的反馈，教师的任务不再是单一的评价对与错，而是和大家一起构建一套能自己迭代改变的反馈系统
+ 考虑心理学的效应，将反馈的规模从整个班级细化到具备信任基础的小组
+ 允许DDL效应，但是不同的人不同的事情，DDL并不统一

总结一下，在这个多变的时代，培养元认知能力，就不能采用传统的教学模式

我们需要的不是努力调整教学课堂的组织形式和考核方式

或许我们真正应该反思的是教学的主体是不是应该从老师变成学生本身，课堂的形式应该让位于主体的需求，大概这就是我真正想要去做教改尝试的内因吧
