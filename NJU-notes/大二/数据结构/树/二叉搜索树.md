# 二叉搜索树 BST

## 定义与性质
- 左子树所有结点 < 根 < 右子树所有结点（**所有**，不是只和直接孩子比！）
- **中序遍历严格递增** —— BST 的灵魂，一切平衡树都靠它
- 查找/插入/删除都是 O(h)；h 最坏 O(n)（按有序序列插入即退化成链表）
- "平均"意义下随机插入 h ≈ O(log n)，但最坏无保证 → 才有后面的平衡树

## 删除三情况（考试高频）
1. 叶子：直接删
2. 只有一个孩子：孩子顶替
3. 两个都有一：用**中序前驱**（左子树最右）或**中序后继**（右子树最左）的值替换，再转化成删前驱/后继（它至多一个孩子）

## 必背骨架
```cpp
Node* erase(Node* t, int x) {
    if (x < t->val) t->l = erase(t->l, x);
    else if (x > t->val) t->r = erase(t->r, x);
    else {
        if (!t->l || !t->r) {                    // 情况1/2 统一处理
            Node* ch = t->l ? t->l : t->r;
            delete t; return ch;
        }
        Node* pre = t->l;                        // 情况3：中序前驱
        while (pre->r) pre = pre->r;
        t->val = pre->val;                       // 换值不动结构
        t->l = erase(t->l, pre->val);
    }
    return t;
}
```

## 常见坑
- 相等元素：插入时 `else if (x > val)` 才插右 → 相等被忽略（键互异）
- 验证 BST（LC98）不能只看父子大小，必须整棵子树都在范围内
