# 伸展树 Splay（不要平衡信息的平衡树）

## 核心思想
- 不存高度/颜色，**任何被访问的节点都旋转到根**（find/insert/erase 都 splay）
- 单次操作最坏 O(n)，但**摊还** O(log n)：对整个操作序列平均
- 白送的性质：最近访问的节点靠近根 → 访问局部性好（缓存原理），适合"8/2 律"数据
- 代码最短，还能做区间翻转等高级操作（竞赛 LCT 的基础）

## splay 双旋策略（考点：为什么不一路单旋？）
```
一字型（z、父、祖父同侧）→ 先转父亲，再转自己
之字型（z 形）           → 连续转自己两次
父即根                  → 单旋一次
```
一路单旋虽然也能到根，但访问路径长度不收缩，摊还界退化为 O(n)；
双旋每步把祖父以下的路径减半，才能证明摊还 O(log n)。

## 必背骨架
```cpp
void rotate(Node* x) {                 // x 转到父的位置（三叉链带父指针）
    Node *p = x->pa, *g = p->pa;
    if (p->l == x) { p->l = x->r; if (x->r) x->r->pa = p; x->r = p; }
    else           { p->r = x->l; if (x->l) x->l->pa = p; x->l = p; }
    x->pa = g; p->pa = x;
    if (!g) root = x;
    else if (g->l == p) g->l = x; else g->r = x;
}
void splay(Node* x) {
    while (x->pa) {
        Node *p = x->pa, *g = p->pa;
        if (!g) rotate(x);
        else {
            if ((g->l == p) == (p->l == x)) rotate(p);  // 一字先转父
            else rotate(x);                              // 之字先转己
            rotate(x);
        }
    }
}
```
