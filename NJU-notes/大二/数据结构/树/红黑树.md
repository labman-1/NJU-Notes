# 红黑树（近似平衡的 BST，std::map/set 的底层）

## 五条性质（背！）
1. 节点非红即黑
2. 根是黑
3. 叶（nil 哨兵）是黑
4. 红节点的孩子必黑（⇒ **没有连续两个红**）
5. 任一节点到其所有后代叶子的路径上**黑节点数相同**（黑高 bh 一致）

## 为什么 O(log n)
性质④⇒ 一条路上至少一半是黑（红不相邻）⇒ `bh >= h/2`；
性质⑤⇒ 黑高为 bh 的子树至少 `2^bh - 1` 个结点；
联立得 `n >= 2^(h/2) - 1`，即 **`h <= 2*log2(n+1)`**。

## 与 AVL 的取舍
- 红黑树放宽平衡（黑高一致即可，不要求每点 |bf|<=1）→ 树稍高一点
- 换来修改极便宜：插入至多 2 次旋转，删除至多 3 次（AVL 删除最坏 O(log n) 次旋转）
- 读多写少选 AVL，写多或不确定选红黑 → 工程界全用红黑

## 插入修复三 case（新节点 z 染红，看叔叔；口诀）
1. **叔红**：父叔变黑、祖父变红，z 上移到祖父（只变色，可能继续向上）
2. **叔黑 + 之字**（z 与父不同侧）：先旋父，化成一字
3. **叔黑 + 一字**（z 与父同侧）：父变黑、祖父变红，反方向旋祖父 → 结束

```cpp
void insertFix(Node* z) {
    while (z->pa->red) {                 // 父黑即合法；父红⇒祖父必存在且黑
        Node* g = z->pa->pa;
        if (z->pa == g->l) {
            Node* u = g->r;              // 叔叔
            if (u->red) { z->pa->red = u->red = false; g->red = true; z = g; }
            else {
                if (z == z->pa->r) { z = z->pa; rotL(z); }        // 之字转一字
                z->pa->red = false; g->red = true; rotR(g);       // 一字
            }
        } else { /* 父在右：完全对称 */ }
    }
    root->red = false;
}
```

## 删除要点（掌握思想）
删黑节点会"欠一个黑高"（双黑），修复看兄弟：
- 兄红：旋转变色，转成兄黑情况
- 兄黑+侄全黑：兄变红、双黑上移
- 兄黑+近侄红远侄黑：旋转成"远侄红"
- 兄黑+远侄红：兄替父色、父变黑、远侄变黑、旋转 —— 结束
