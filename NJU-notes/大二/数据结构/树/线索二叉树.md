# 线索二叉树（Threaded Binary Tree）

## 动机
n 个结点的二叉链表有 **2n 个指针域，其中 n+1 个是空的**（n-1 个用于连孩子）。
一半以上的空间浪费 → 空左指针存**中序前驱**，空右指针存**中序后继**，加 tag 标记区分：
`ltag=0` 左指针是孩子；`ltag=1` 是前驱线索（rtag 同理，指后继）。

## 线索化 = 改造中序遍历（一边遍历一边连线索）
```cpp
Node* pre = nullptr;                    // 中序里刚访问过的结点
void threading(Node* p) {
    if (!p) return;
    threading(p->l);
    if (!p->l) { p->l = pre;  p->ltag = 1; }          // 我没左孩子→左指前驱
    if (pre && !pre->r) { pre->r = p; pre->rtag = 1; } // 前驱没右孩子→其右指我
    pre = p;
    threading(p->r);
}
```

## 找中序后继 O(h)（无右子树时 O(1)）
```cpp
Node* next(Node* p) {
    if (p->rtag == 1) return p->r;      // 有线索直接拿
    Node* q = p->r;                      // 无线索：右子树最左
    while (q && q->ltag == 0) q = q->l;
    return q;
}
```
遍历：先走到最左结点（中序第一个），反复 next —— **不用栈不用递归**。

## 考点
- 数空链域：n+1（2n - (n-1)）
- 第一个结点的前驱线索、最后一个结点的后继线索指向 NULL（或带头结点的写法指回头结点）
- 中序线索二叉树里找前驱/后继的两种情况（有/无右子树）
- **Morris 遍历** = 临时线索化：借右空指针指回后继、遍历后还原，O(1) 空间遍历任意二叉树（LC94、LC99）
