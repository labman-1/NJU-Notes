- 渐增式地开发rdt的发送方和接收方
- 只考虑单向数据流动（控制信息是双向的！）
- 使用有限状态机进行描述
目标：需要在底层数据通道的不可靠性之上向上层提供rdt

# RDT1.0
初始假设底层信道是完全可靠的，此时传输层要做的事非常简单。
- 发送方：接收上层传下来的data，打包，扔进下层
- 接收方：收到包，解复用，交付给上层

# RDT 2.0
经具有比特差错信道，bit可能翻转
使用 **自动重传请求**（ABQ）协议，具备另外三种功能：
- 差错检测：比如UDP使用因特网检验和字段
- 接收方反馈：ACK与NAK
- 重传
![[可靠数据传输（RDT）_202611101919.png]]
rdt2.0并未考虑到ACK或NAK分组受损的可能性，这使得它不是完备的。ACK或NAK分组受损之后发送方将难以确定下一个状态。
