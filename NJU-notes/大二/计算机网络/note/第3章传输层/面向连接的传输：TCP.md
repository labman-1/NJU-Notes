# 流量控制
目的：让发送方不至于发送得太快，以至于超过接收方的接收能力。
通过捎带技术把自己空闲缓冲区的大小告诉对方。
# 连接
连接的本质是：
- 知道对方要通信
- 准备好资源
- 一些控制变量需要置位（连接的初始序号、初始化的recieve buffer的大小等）
