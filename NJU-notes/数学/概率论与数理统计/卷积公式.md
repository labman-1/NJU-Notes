这两个公式其实是同一件事的两个方向：**概率质量的搬运**。单调变换是把一根轴上的质量重新摊到另一根轴上——拉伸多少倍，密度就稀释多少倍；卷积是把平面上的质量沿斜线累加后投影到一根轴上。先把“搬运”这个图像建立起来，公式就只是它的代数表达。

先看单调变换公式是怎么“长出来”的：
## 一、单调变换公式：f_Y(y) = f_X(h(y))·|h′(y)|

### 1. 两条推导路线，殊途同归

**路线一：CDF 法（万能，先掌握它）**

对 Y = g(X)，五步走：

```
① 求 Y 的值域          → 决定 f_Y 在哪里非零
② 写 F_Y(y) = P(g(X) ≤ y)
③ 解不等式 g(X) ≤ y，翻译成 X 的事件
④ 用 f_X 算出这个事件的概率
⑤ 对 y 求导，得 f_Y(y)
```

单调增时，`g(X) ≤ y ⟺ X ≤ h(y)`，于是 `F_Y(y) = F_X(h(y))`，链式求导得 `f_Y(y) = f_X(h(y))·h′(y)`，此时 h′ > 0。

单调减时，`g(X) ≤ y ⟺ X ≥ h(y)`，于是 `F_Y(y) = 1 − F_X(h(y))`，求导得 `−f_X(h(y))·h′(y)`，此时 h′ < 0，负负得正。

**两种情况合并，就出现绝对值**：`f_Y(y) = f_X(h(y))·|h′(y)|`。绝对值不是为了“好看”，而是单调减那半边的负号被收进来了——本质是保证密度非负。

**路线二：微元守恒（上面那张图）**

落在 `[y, y+dy]` 的概率 = 落在它原像 `[x, x+dx]` 的概率（同一批质量）：

```
f_Y(y)·dy = f_X(x)·dx，其中 dx = |h′(y)|·dy
⇒ f_Y(y) = f_X(h(y))·|h′(y)|
```

### 2. 为什么是 |h′|：拉伸与稀释

h′ 是映射的**局部拉伸率**。橡皮筋拉长 2 倍，同样的珠子摊在 2 倍长度上，线密度减半。X 轴经 g 拉伸 |h′| 倍，密度就要除以 |h′|——公式里的乘法其实是“稀释”。

一个直接的应用：X ~ E(λ)，Y = cX（c > 0）时，h(y) = y/c，|h′| = 1/c，所以

```
f_Y(y) = (λ/c)·e^(−λy/c)   即 Y ~ E(λ/c)
```

**率被除以 c**。这就是 23 秋四里求 Z = X + 2Y 时要先把 2Y 看成“率减半的指数变量”的原因——线性拉伸改率，不改指数形状。

### 3. 三个例子，覆盖三种情形

**例 1｜单调，公式直接用**：X ~ U(0,1)，Y = X²。值域 (0,1)，h(y) = √y，|h′| = 1/(2√y)：

```
f_Y(y) = 1/(2√y)，0 < y < 1
```

自检：∫₀¹ 1/(2√y) dy = [√y]₀¹ = 1 ✓。注意密度在 0 附近无界——这就是“密度可以大于 1 甚至无界，但积分必须是 1”的活例子。

**例 2｜非单调，公式失效，数原像**：X ~ N(0,1)，Y = X²。g 在全轴不单调，不能套公式。老老实实走 CDF：`P(X² ≤ y) = P(−√y ≤ X ≤ √y)`，**两个原像都要数进来**：

```
F_Y(y) = 2Φ(√y) − 1    ⇒    f_Y(y) = [f_X(√y) + f_X(−√y)] / (2√y) = e^(−y/2)/√(2πy)，y > 0
```

这就是 χ² 分布的雏形。对称分布时两个原像贡献相等；不对称时（如 X~U(−1,2)，Y=X²）两边不相等，别想当然。

**例 3｜截断，公式会漏，CDF 不会**：X ~ E(1)，Y = min(X, 3)。Y 在 3 处有一坨概率质量 e⁻³（P(X≥3) 整体堆到 Y=3），它是“连续 + 离散”的混合分布。如果只对 0<y<3 写密度 e⁻ʸ，积分不到 1——**凡是有 min/max/取整的变换，只信 CDF 法**。

### 4. 路线权衡

| 路线 | 适用 | 优点 | 风险 |
|---|---|---|---|
| CDF 五步法 | 一切变换 | 不会漏跳跃、截断、混合 | 步骤多，易在求导处出错 |
| 单调公式 | 支持域上严格单调 | 一步出结果 | 非单调时套用 = 全错；容易忘写值域 |
| 微元守恒 | 快速检验 | 直觉强 | 不是严格推导，不能单独交卷 |

考场建议：**用公式算，用 CDF 的思路检查值域和端点**。公式是快路，CDF 是护栏。

接着是卷积。它和边缘密度是同一个动作——切片积分——只是刀的方向不同：
## 二、卷积公式：f_Z(z) = ∫ f(x, z−x) dx

### 1. 它不是需要背的公式，是一句几何直译

从定义出发：

```
F_Z(z) = P(X+Y ≤ z) = ∬_{x+y≤z} f(x,y) dx dy
```

区域是斜线 x+y=z 左下方的半平面。**横着切**（固定 y，x 从 −∞ 积到 z−y）：

```
F_Z(z) = ∫ [ ∫_{−∞}^{z−y} f(x,y) dx ] dy
```

对 z 求导（变上限求导，内层上限 z−y 的导数是 1）：

```
f_Z(z) = ∫ f(z−y, y) dy  ——换元 x = z−y，就是 ∫ f(x, z−x) dx
```

所以三个公式其实是**同一把刀的三个方向**：

| 公式 | 刀的方向 | 沿什么积 |
|---|---|---|
| f_X(x) = ∫ f(x,y) dy | 竖线 | y 方向 |
| f_Y(y) = ∫ f(x,y) dx | 横线 | x 方向 |
| f_{X+Y}(z) = ∫ f(x, z−x) dx | 斜线 x+y=z | 沿斜线 |

全都是 `P((X,Y)∈D) = ∬_D f` 的特例，只是区域形状不同。理解了这一点，卷积不需要单独记忆。

### 2. 独立才可拆：两套公式的分界线

```
一般：      f_Z(z) = ∫ f_{X,Y}(x, z−x) dx     ← 保留联合密度
独立时：    f_Z(z) = ∫ f_X(x) · f_Y(z−x) dx   ← 才能换成边缘乘积
```

理由和 E(XY)=EX·EY 一模一样：只有 `f(x,y) = f_X(x)f_Y(y)` 时，`f(x, z−x)` 才能拆成乘积。**不独立时硬套第二个公式，等于拿两个边缘密度冒充联合密度**——积分出来是 1，但根本不是 Z 的分布，错得悄无声息。

22 秋四就是设了这个坑：0<y<x<1 上 f = 3x，X、Y 不独立。正确做法是保留联合密度并让支持域说话：

```
代 y = z−x，条件 0 < z−x < x < 1  ⟺  x < z，x > z/2，x < 1

0 < z < 1：  x ∈ (z/2, z)   →  f_Z = ∫_{z/2}^{z} 3x dx = 9z²/8
1 ≤ z < 2：  x ∈ (z/2, 1)   →  f_Z = ∫_{z/2}^{1} 3x dx = 3/2 − 3z²/8
```

### 3. 定限四步法：积分限从图里来，不从公式里来

1. **画支持域 D**；
2. 让斜线 x+y=z 从左下往右上平移；
3. 斜线**首次接触** D 的位置给出 z 的下界，**完全离开**给出上界；
4. 斜线每经过一个**顶点 (x₀, y₀)**，截线形态改变一次 → 分段点就是 **z = x₀ + y₀**。

上图右边的三角形分布就是这条流程的产物：独立 U(0,1)+U(0,1)，正方形顶点投影到 z 轴得 0、1、1、2，于是 0<z<1 段 f_Z = z（teal 上升段），1<z<2 段 f_Z = 2−z（coral 下降段）。这就是著名的三角形分布。

### 4. 经典结论：E(λ) + E(λ) = Γ(2,λ)，不是 E(2λ)

```
f_Z(z) = ∫₀^z λe^(−λx) · λe^(−λ(z−x)) dx = λ²e^(−λz) ∫₀^z dx = λ²z·e^(−λz)
```

两个 λ 在积分中抵消，**多出来一个 z**——这就是和的形状（Gamma 形）。直觉：指数的“无记忆性”被相加破坏了，所以和不再是指数。

**对比记忆**：min(X,Y) 才是 E(2λ)（率相加，无记忆性保持）；**和是 Γ 形，min 是指数**，方向千万别反。24 春四的“备用系统”（一个坏了另一个顶上，寿命 = X+Y）考的就是前者。

### 5. 什么时候该绕开卷积——路线权衡

| 情形 | 更快的路线 | 理由 |
|---|---|---|
| 只问 E(Z)、D(Z) | E/D 性质，两行结束 | 根本不需要分布（24 春五就是这样） |
| (X,Y) 二维均匀 | F_Z(z) = 面积比，再求导 | 几何代替积分，25 秋 \|X−Y\| 就是这么做的 |
| 独立正态 + 正态 | 直接结论 Z ~ N(μ₁+μ₂, σ₁²+σ₂²) | 卷积的已知结果，当公式用 |
| Z = X+2Y 这类 | 先令 V=2Y（指数率减半），再卷积 | 化成标准 X+V，少出错 |
| 离散或混合型 | CDF 法 | 有概率质量点，没有密度可卷 |
| Z = max/min | 极值公式 | 和的公式用不上 |

**动笔前先问一句：题目要的是分布，还是只要数字特征？** 要分布才卷积；只要 E 和 D，卷积是彻底的弯路。

### 6. 交卷前自检三件套

- f_Z ≥ 0，且 ∫f_Z dz = 1（不成立说明漏了分段或常数错）；
- z 的取值范围 = D 的各顶点 z = x₀+y₀ 的最小值到最大值；
- 用算出的 f_Z 积分验证 E(Z) = EX + EY——对不上必错。

两个公式的共同底色：**总质量守恒**。变换公式靠 |h′| 保证搬运后总质量不变；卷积靠斜线扫遍整个支持域保证不重不漏。所以两套公式的自检手段也一样——积回 1。

## 一页回顾：两个公式对照

| | 单调变换公式 | 卷积公式 |
|---|---|---|
| **解决的问题** | 已知 f_X，求 Y=g(X) 的密度 | 已知 f_{X,Y}，求 Z=X+Y 的密度 |
| **公式** | f_Y(y) = f_X(h(y))·\|h′(y)\| | f_Z(z) = ∫ f(x, z−x) dx |
| **几何本质** | 质量搬运：轴拉伸 \|h′\| 倍，密度稀释 \|h′\| 倍 | 斜线切片：沿 x+y=z 把密度累加 |
| **推导入口** | CDF 法 + 链式求导（绝对值来自单调减分支的负号） | 二重积分横切 + 变上限求导 |
| **成立条件** | g 在**支持区间**上严格单调可微 | 无条件；换成边缘乘积版才需要独立 |
| **头号陷阱** | 非单调（X²）要数全部原像；min 截断有端点质量 | 不独立时硬套 f_X·f_Y 版全错 |
| **自检** | 积回 1；值域 = g(X) 的范围 | 积回 1；z 范围 = 顶点投影；E(Z)=EX+EY |

**三个最容易考到的推论**，建议背下来当结论用：

1. `E(λ)` 经线性拉伸 cX 后变成 `E(λ/c)`——率被除，形状不变（23 秋四的预处理步骤）；
2. 两个独立 `E(λ)` 之和是 `Γ(2,λ)`（密度 λ²ze^{−λz}），**不是** E(2λ)；min(X,Y) 才是率相加的 E(2λ)；
3. 独立 U(0,1)+U(0,1) 是三角形分布（z 与 2−z 两段），分段点 = 支持域顶点的 z=x+y 投影。
