**全章骨架**：2 个不等式（工具）→ 2 种收敛（语言）→ 3 个大数定律（平均的稳定性）→ 3 个中心极限定理（和的渐近正态性）。

**一句话主线**：不等式是证明的工具，收敛是描述"极限行为"的语言；大数定律说"平均值稳定下来了"，中心极限定理进一步说"围绕平均值的波动是正态的"。

## 0. 一页总览

| 板块   | 名称       | 条件关键词                           | 结论一句话                                                            |
| :--- | :------- | :------------------------------ | :--------------------------------------------------------------- |
| 不等式  | 马尔可夫     | $X \ge 0$，$E(X)$ 有限             | $P(X \ge a) \le E(X)/a$                                          |
| 不等式  | 切比雪夫     | $E(X), D(X)$ 存在                 | $P(\|X-\mu\| \ge \varepsilon) \le \sigma^2/\varepsilon^2$        |
| 收敛   | 依概率收敛    | $\forall \varepsilon > 0$       | $P(\|X_n - X\| \ge \varepsilon) \to 0$                           |
| 收敛   | 依分布收敛    | 在 $F$ 的连续点处                     | $F_n(x) \to F(x)$                                                |
| 大数定律 | 切比雪夫     | 独立，期望、方差存在，**方差一致有界**           | $\overline{X}_n - \overline{\mu}_n \xrightarrow{P} 0$            |
| 大数定律 | 伯努利      | $n$ 重伯努利试验                      | 频率 $f_n \xrightarrow{P} p$                                       |
| 大数定律 | 辛钦       | **独立同分布**，期望存在（**不要方差**）        | $\overline{X}_n \xrightarrow{P} \mu$                             |
| 中心极限 | 林德伯格–列维  | 独立同分布，$\sigma^2 \in (0,\infty)$ | $\dfrac{\sum X_i - n\mu}{\sigma\sqrt{n}} \xrightarrow{d} N(0,1)$ |
| 中心极限 | 棣莫佛–拉普拉斯 | $X \sim B(n,p)$                 | $\dfrac{X - np}{\sqrt{npq}} \xrightarrow{d} N(0,1)$              |
| 中心极限 | 李雅普诺夫    | 独立**不同分布** + 李雅普诺夫条件            | $\dfrac{\sum X_i - \sum\mu_i}{B_n} \xrightarrow{d} N(0,1)$       |

记号约定：$\overline{X}_n = \frac{1}{n}\sum_{i=1}^n X_i$；$\Phi(x)$ 为标准正态分布函数；$\xrightarrow{P}$ 表示依概率收敛，$\xrightarrow{d}$ 表示依分布收敛。

## 1. 两个不等式

### 1.1 马尔可夫不等式

- **条件**：$X$ 为非负随机变量（$X \ge 0$），$E(X)$ 存在且有限。
- **结论**：对任意 $a > 0$，
  $$P(X \ge a) \le \frac{E(X)}{a}.$$
- **证明思路（一句话）**：由 $X \ge a \cdot 1_{\{X \ge a\}}$ 两边取期望、移项即得。
- **要点**：它是切比雪夫不等式的"母体"——对非负变量 $(X-\mu)^2$ 使用马尔可夫不等式即导出切比雪夫不等式；控制"非负量取大值"的概率，只用到一阶矩。

### 1.2 切比雪夫不等式

- **条件**：$E(X) = \mu$、$D(X) = \sigma^2$ 均存在（有限），**不要求知道 $X$ 的具体分布**。
- **结论**：对任意 $\varepsilon > 0$，
  $$P(|X - \mu| \ge \varepsilon) \le \frac{\sigma^2}{\varepsilon^2}, \qquad \text{等价地} \quad P(|X - \mu| < \varepsilon) \ge 1 - \frac{\sigma^2}{\varepsilon^2}.$$
  取 $\varepsilon = k\sigma$ 得常用形式：$P(|X - \mu| \ge k\sigma) \le \dfrac{1}{k^2}$，即 $P(\mu - k\sigma < X < \mu + k\sigma) \ge 1 - \dfrac{1}{k^2}$（$k=2$ 时下界 $3/4$，$k=3$ 时下界 $8/9$）。
- **证明思路（一句话）**：$P(|X-\mu| \ge \varepsilon) = P((X-\mu)^2 \ge \varepsilon^2) \le \dfrac{E[(X-\mu)^2]}{\varepsilon^2} = \dfrac{\sigma^2}{\varepsilon^2}$（对 $(X-\mu)^2$ 用马尔可夫）。
- **考点用法**：① 已知期望、方差估计概率（"至少有多大概率落在若干倍标准差内"）；② 证明大数定律的核心工具。
- **注意**：给出的只是**界**，不是精确概率；界可能很松（如 $1/k^2 > 1$ 时无信息）。

## 2. 两个收敛

### 2.1 依概率收敛 $X_n \xrightarrow{P} X$

- **定义**：若对任意 $\varepsilon > 0$，
  $$\lim_{n \to \infty} P(|X_n - X| \ge \varepsilon) = 0 \quad \left(\text{即 } P(|X_n - X| < \varepsilon) \to 1\right),$$
  则称 $X_n$ **依概率收敛**于 $X$。
- **直觉**：样本量增大后，$X_n$ 与 $X$ 的偏差超过任意小量 $\varepsilon$ 的**可能性**消失；不要求每一次实现都接近，是概率意义上的收敛。
- **典型例子**：频率收敛于概率（伯努利大数定律）、$\overline{X}_n$ 收敛于 $\mu$（辛钦大数定律）。

### 2.2 依分布收敛 $X_n \xrightarrow{d} X$

- **定义**：设 $F_n(x)$、$F(x)$ 分别为 $X_n$、$X$ 的分布函数，若在 $F(x)$ 的**所有连续点**处
  $$\lim_{n \to \infty} F_n(x) = F(x),$$
  则称 $X_n$ **依分布收敛**于 $X$，记 $F_n \Rightarrow F$。
- **为什么只要求连续点**：极限分布有跳跃点时，$F_n$ 在跳跃点处可以不收敛到 $F$。例：$X_n \equiv 1/n$，$X \equiv 0$，在 $x = 0$ 处 $F_n(0) = 0$ 不趋于 $F(0) = 1$，但在其余所有点都收敛，仍是依分布收敛。

### 2.3 两者关系（高频考点）

| 关系 | 结论 |
| :--- | :--- |
| 依概率 $\Rightarrow$ 依分布 | **成立** |
| 依分布 $\Rightarrow$ 依概率 | **一般不成立**（分布收敛不排除个别小概率大偏差） |
| 极限为常数 $c$ 时 | 依分布收敛于 $c$ $\iff$ 依概率收敛于 $c$（**重要特例**） |

## 3. 三个大数定律

**直观含义**：大量重复观测的算术平均稳定于其期望——"频率稳定于概率、均值稳定于期望"的严格数学表述。

### 3.1 切比雪夫大数定律

- **条件**：$X_1, X_2, \dots$ **相互独立**（两两独立即可）；各 $E(X_i) = \mu_i$、$D(X_i) = \sigma_i^2$ 存在；且**方差一致有界**：存在常数 $C$ 使 $\sigma_i^2 \le C$ 对一切 $i$ 成立。
- **结论**：对任意 $\varepsilon > 0$，
  $$P\left(\left|\frac{1}{n}\sum_{i=1}^n X_i - \frac{1}{n}\sum_{i=1}^n \mu_i\right| \ge \varepsilon\right) \to 0.$$
  **特例（最常用形式）**：若诸 $X_i$ 独立同分布且 $E(X_i) = \mu$、$D(X_i) = \sigma^2 < \infty$，则 $\overline{X}_n \xrightarrow{P} \mu$。
- **证明核心（一句话）**：对 $\overline{X}_n$ 用切比雪夫不等式，$D(\overline{X}_n) = \frac{1}{n^2}\sum \sigma_i^2 \le \frac{C}{n} \to 0$。

### 3.2 伯努利大数定律

- **条件**：$n_A$ 为 $n$ 重伯努利试验中事件 $A$ 发生的次数，$p = P(A)$，$f_n = n_A / n$ 为频率。
- **结论**：对任意 $\varepsilon > 0$，$f_n \xrightarrow{P} p$，即
  $$\lim_{n \to \infty} P(|f_n - p| \ge \varepsilon) = 0.$$
- **意义**：第一次严格证明了"**频率稳定于概率**"，是概率的统计定义的理论依据。
- **地位**：三大定律的特例——令 $X_i$ 为第 $i$ 次试验中 $A$ 发生的指示变量（$X_i \sim B(1,p)$），即化为辛钦（或切比雪夫）大数定律。

### 3.3 辛钦大数定律

- **条件**：$X_1, X_2, \dots$ **独立同分布**，期望 $E(X_i) = \mu$ 存在（**不要求方差存在！**）。
- **结论**：$\overline{X}_n \xrightarrow{P} \mu$。
- **地位**：条件最"省"——用"同分布"换掉了"方差存在且有界"，是应用最广的大数定律（矩估计相合性的理论来源）。

### 3.4 三大定律条件对比（判断题高频）

| 定律 | 独立性 | 同分布 | 期望 | 方差 | 结论 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 切比雪夫 | 独立（或两两独立） | 不要求 | 各 $\mu_i$ 存在 | 存在且**一致有界** | $\overline{X}_n - \overline{\mu}_n \xrightarrow{P} 0$ |
| 伯努利 | 伯努利试验序列 | 是（0-1 分布） | $\mu = p$ | $p(1-p)$ 自动有界 | $f_n \xrightarrow{P} p$ |
| 辛钦 | 独立 | **是** | $\mu$ 存在 | **不要求** | $\overline{X}_n \xrightarrow{P} \mu$ |

记忆口诀：**切比雪夫管住方差（不同分布也行），辛钦管住同分布（不要方差），伯努利是两者在 0-1 变量上的化身。**

## 4. 三个中心极限定理

**直观含义**：大量独立、单个影响微小的随机因素叠加，其总和标准化后近似服从标准正态分布——这是正态分布广泛存在的理论解释。

### 4.1 林德贝格–列维（独立同分布）中心极限定理

- **条件**：$X_1, X_2, \dots$ **独立同分布**，$E(X_i) = \mu$，$D(X_i) = \sigma^2 \in (0, +\infty)$。
- **结论**：对任意实数 $x$，
  $$\lim_{n \to \infty} P\left(\frac{\sum_{i=1}^n X_i - n\mu}{\sigma\sqrt{n}} \le x\right) = \Phi(x).$$
  即近似地 $\sum X_i \sim N(n\mu,\ n\sigma^2)$，等价地 $\overline{X}_n \sim N(\mu,\ \sigma^2/n)$（近似）。
- **计算模板**：
  $$P\left(\sum X_i \le a\right) \approx \Phi\left(\frac{a - n\mu}{\sigma\sqrt{n}}\right), \qquad P(a \le \overline{X}_n \le b) \approx \Phi\left(\frac{(b-\mu)\sqrt{n}}{\sigma}\right) - \Phi\left(\frac{(a-\mu)\sqrt{n}}{\sigma}\right).$$

### 4.2 棣莫佛–拉普拉斯中心极限定理（二项分布的正态近似）

- **条件**：$X \sim B(n, p)$（即 $n$ 个独立 $B(1,p)$ 之和），记 $q = 1-p$。
- **结论**：
  $$\frac{X - np}{\sqrt{npq}} \xrightarrow{d} N(0,1), \quad \text{即 } X \approx N(np,\ npq).$$
- **地位**：林德伯格–列维定理的特例（$B(1,p)$ 的 $\mu = p$、$\sigma^2 = pq$）。
- **计算模板**：$P(a \le X \le b) \approx \Phi\left(\dfrac{b - np}{\sqrt{npq}}\right) - \Phi\left(\dfrac{a - np}{\sqrt{npq}}\right)$；如课程要求，可加**连续性修正**（$b \to b + 0.5$，$a \to a - 0.5$）。
- **近似选取**：$np$、$nq$ 都较大 → 用本定理（正态近似）；$p$ 很小、$np = \lambda$ 适中 → 用泊松近似（见 [[常见概率分布汇总表]]）。

### 4.3 李雅普诺夫中心极限定理

- **条件**：$X_1, X_2, \dots$ **相互独立（可不同分布）**，$E(X_i) = \mu_i$、$D(X_i) = \sigma_i^2 > 0$，记 $B_n^2 = \sum_{i=1}^n \sigma_i^2$；若存在 $\delta > 0$ 使
  $$\frac{1}{B_n^{2+\delta}} \sum_{i=1}^n E\left(|X_i - \mu_i|^{2+\delta}\right) \xrightarrow{n \to \infty} 0,$$
  则称满足**李雅普诺夫条件**（含义：每个变量相对于总波动可忽略，没有"一家独大"的项）。
- **结论**：
  $$\frac{\sum_{i=1}^n X_i - \sum_{i=1}^n \mu_i}{B_n} \xrightarrow{d} N(0,1).$$
- **地位**：去掉同分布要求，最一般；林德伯格–列维是其特例。

### 4.4 三个中心极限定理对比

| 定理 | 独立 | 同分布 | 标准化的分母 | 结论 |
| :--- | :--- | :--- | :--- | :--- |
| 林德伯格–列维 | 是 | **是** | $\sigma\sqrt{n}$ | $\dfrac{\sum X_i - n\mu}{\sigma\sqrt{n}} \xrightarrow{d} N(0,1)$ |
| 棣莫佛–拉普拉斯 | 是 | 是（0-1 分布） | $\sqrt{npq}$ | $\dfrac{X - np}{\sqrt{npq}} \xrightarrow{d} N(0,1)$ |
| 李雅普诺夫 | 是 | **不要求** | $B_n = \sqrt{\sum \sigma_i^2}$ | $\dfrac{\sum X_i - \sum\mu_i}{B_n} \xrightarrow{d} N(0,1)$ |

## 5. 大数定律与中心极限定理的关系

| | 大数定律 | 中心极限定理 |
| :--- | :--- | :--- |
| 刻画对象 | $\overline{X}_n - \mu$ **本身**趋于 0 | $\sqrt{n}(\overline{X}_n - \mu)/\sigma$ 的**极限分布** |
| 精细程度 | 粗（只说"差消失"） | 细（给出差的确切数量级 $\sim 1/\sqrt{n}$ 及波动分布） |
| 收敛类型 | 依概率收敛 | 依分布收敛 |
| 联系 | 由 CLT 可推出大数定律：$\overline{X}_n - \mu = \dfrac{\sigma}{\sqrt{n}} \cdot \dfrac{\overline{X}_n - \mu}{\sigma/\sqrt{n}}$，前者因子趋于 0、后者依分布有界，故乘积依概率趋于 0 | |

## 6. 考点与易错点清单

1. **切比雪夫不等式**只依赖期望和方差，不知道分布也能用；但给出的是界而非精确值。两个等价形式（$\ge \varepsilon$ 上界 / $< \varepsilon$ 下界）都要熟。
2. **判断题最爱**：辛钦大数定律**不要求方差存在**；切比雪夫大数定律**不要求同分布**但要求**方差一致有界**。"独立同分布 + 期望存在"就足够用辛钦。
3. **收敛关系**：依概率 $\Rightarrow$ 依分布；反之一般不成立；**极限为常数时两者等价**。
4. 依分布收敛只要求在 $F$ 的**连续点**收敛（跳跃点可以不收敛）。
5. **CLT 标准化**方向：和的标准化是"减 $n\mu$、除 $\sigma\sqrt{n}$"（不是除 $n\sigma^2$）；均值的标准化是"除 $\sigma/\sqrt{n}$"。
6. **二项分布近似**的选取：$np$、$nq$ 均较大用正态近似；$p$ 小、$\lambda = np$ 适中用泊松近似。
7. 中心极限定理**没有说** $X_i$ 本身接近正态——接近正态的是**标准化后的和/均值**。
8. **常见题型**：① 给定 $E$、$D$ 用切比雪夫不等式估计概率（常考 $k=2,3$）；② 验证某序列满足哪个大数定律；③ 用 CLT 近似计算 $n$ 个独立同分布变量之和落在某区间的概率（含 $B(n,p)$ 情形）；④ 由 CLT 反求 $n$（使近似概率达到要求）。
