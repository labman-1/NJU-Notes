# CTDP/RSIP 协议文本 v1.9

## 根本目标（宪法序言，2026-10-07 立·用户原话）

本协议、国策树与全部工具存在的最终目的：

- 经济独立、财富自由
- 让父母不用再为几块钱的差价而四下比对
- 活得久一点
- 亲自玩到体感游戏、全息游戏——赛博飞升

立法注记：这些不是"天真的想法"，是远端 `V(τ)`——它们显得"没那么强力"，只因贴现函数 `W(τ)` 对所有人同样陡峭，远端价值被系统性抹平。协议的全部结构（链/预约/国策/被动机制）是把远端价值搬运到近端的机器：**不修欲望，修搬运工**。任何条款修订不得与根本目标冲突；判例裁决遇到模糊地带时，向根本目标对齐。

## 全局定义：日界（2026-09-29 v1.3）

协议中一切"一天"（G1 评分归属、G3 周判定边界、G4 日配额刷新、国策当日凭证/每日上树配额）以**凌晨 4:00** 为分界——0:00–3:59 属于前一"天"（二游式刷新，适配 12 点后入睡的作息）。App 内 `dayKey` 已全量统一（logic/day.ts，评分与国策共用）。

## C1 主链定义

- 任务：**每日算法题（本业）**——满状态专注 60 分钟，读题→构思→实现→总结一体的深度专注，不凑题量
- 时长：满状态专注 60 分钟
- 触发扳机：发送 `[C1] 触发` + 手机翻面扣桌/离手
- 门槛：没把握保持满状态一小时就不许触发（不触发无任何损失）
- 计数：成功 = 消息序号 +1；失败 = 计数归零，从 #1 重来
- 周末条款：C1 不分工作日/周末，照常执行（算法不吃 DDL）；周末优先走预约链（无 DDL 日启动阻力天然更大，两极分化的高危场景）
- **OJ 入链修订（2026-10-07 裁决；2026-10-11 扩围）**：**数据结构课程及作业**（OJ/lab/复习刷题）专注满 1h 可作为 C1 合法触发场景记节点——入链非为防拖延（有 DDL 自驱），是给已有执行流接上正反馈（链长 3 的困境一半源于最稳定的算法执行被协议排除在计数外）。听课是否计节点待首次实践按下必为例裁决。
- **作业启动工具泛化（2026-10-11）**：侦查与预约适用域从算法题扩至一切"会拖到极限"的作业——布置日侦查一次（打开读 5 分钟，消除未知焦虑：拖延的燃料是对任务规模的想象而非任务本身），开工用预约（把"写 lab"平移成"15 分钟后打开文档看第一题"）。
- **晚间三型排班（2026-10-11，替代"每日晚间主场"）**：运动晚=恢复在岗，回来一个侦查即全胜；晚课晚=课后预约或侦查低配；空白晚=C1 节点/预约主场，侦查保底。原则：每种日子都有一扇推得开的门（零敲牛皮糖）。

## 辅助链（预约链）

- 信号：发送 `[C1预约]` + 手机时钟 15 分钟倒计时
- 义务：响铃后立即触发主链
- 失约：按"下必为例"二选一裁决

### 预约链软件化条款（2026-09-23 v0.3 入役）

- App 内预约状态机：`idle → booked(15 分钟倒计时) → due(宽限 5 分钟) → overdue(强制裁决)`
- 兑现 = 窗口内（含宽限）点击触发主链；App 自动为预约链记一个 done（双事件提交）
- 失约裁决沿用"下必为例"：判失败 → 预约链清零（主链不受连坐）；判允许 → 记判例
- **设计判决（2026-09-23，否决自动化提案）**：触发与完成保持人工点击——它们是承诺行为的封印（工作量证明）；"自动成功 + 事后撤销"被否决，理由：协议中沉默=违约信号而非确认信号；最小阻力路径必须指向诚实；事后修正由事件流天然支持（done 之后可追加 fail/verdict 裁决事件，派生视图自动正确，无需撤销机制与时间锁参数）
- C2 锻炼链的辅助链（装包→出门→到达）为纯物理层协议，不经 App

## C2 主链定义（2026-09-23 添加）

- 任务：**锻炼**——校园跑一次，或健身房锻炼 40 分钟至 1 小时
- 触发点：抵达运动场地、开始热身（App 内点"触发"与物理动作绑定）
- 节点 = 完成一次合格锻炼（40min-1h 完整流程，防"到健身房划水 20 分钟就走"）

- 设计注记：此辅助链为"启动链条化"（拆解多段微承诺），非原文的时延型预约链——两者互补，均合法

## C3 课程工程作业链（2026-10-12 建立）

- 任务：**课程工程作业**（计网 lab/hw、ics pa/hw、dlco 实验等工程攻坚类）——一次节点 = 专注推进 60 分钟
- 触发=打开作业文档开始攻坚；与 C1 分工：**算法类（刷题/OJ 写代码）→ C1，工程实验类 → C3**；灰色地带按下必为例裁决
- 需求准入证据：每周 DDL 踩点为自认事实；作业启动工具（侦查+预约泛化）已就位
- **链只记输出（总原则，2026-10-12）**：C1 只管写的部分（刷算法题），C3 只管作业攻坚；一切"学/看/读"类输入（看网课、学算法理论、读教材）不入链——价值由三色预算绿区记录，设备分工已天然区分（电脑端网课自由，手机端 B站=娱乐限额）

## 链间规则

- C1/C2/C3 各自计数、各自清零、互不连坐（原文：链是分布式去中心化的，聚餐荒废几天约束力不磨损）
- App 顶栏点击链名切换当前链；事件按当前链记录
- 链按行为类型分不按科目分（原文兵种逻辑）：C1=算法输出，C2=锻炼，C3=课程工程输出

## 裁决规则（下必为例）

疑似违规只允许二选一，当场在小号登记：

1. 判失败：链清零，从 #1 重来；或
2. 判允许：写判例（编号永久生效，同类情况永久适用）

不允许"这次算了"。

### 被动国策条款（2026-10-06 v1.4 定案）

- **计数模型按类型分叉**：semi/active = done 事件按日去重（现行）；passive = **存续区间天数**自动累计——`[上树, 熄灭)` 含头不含尾，在树段含上树日与今日，熄灭即清算该段，重上重新累计、历史不清零。语义：被动国策的内化不是习惯而是**常驻基础设施的累计存续时长**。
- **免凭证上树**：passive 跳过当日凭证检查（"做到"= 机制配置完成，新建即成立）；全局每日配额对所有类型照旧生效。
- **退出每日结算**：passive 不出现在结算弹窗与睡前软引导中（树上显示中性"在岗"标签）。
- **失效/违例唯一路径 = 主动申报**：发现机制静默失效（系统更新重置白名单等）或主动破契时，手动熄灭（连坐规则照旧），修复后从末梢重上。
- **设计判例（否决"自动勾选"，采纳"区间计数"）**：被动机制会静默失效且失效时本人不知情，自动记成功会把"失效三周未察觉"记成正常守岗；且每日无信息量勾选会训练肌肉记忆、稀释结算仪式对半被动国策的诚实自查价值。区间计数不违背"沉默是金"否决先例：链的失败是高频行为判定（沉默大概率=没做），被动国策的失败是低频结构事件（罕见、主动申报制），"没有事件就没有判定"，事件流只留结构性事实（上树/熄灭/重上）。
- **评分软引导裁决（2026-10-06）**：评分后的"还有 N 条国策未结算"提示维持匿名数字文案（否决列名方案——国策多了列名会爆行，勾选时反正会看内容）。已知并接受两处语义冗余：①评分类国策（G1）自指——评分是睡前最后动作，G1 永远"评完分才轮到结算"，每次被自己催一遍，勾掉即可（1 秒成本）；②周频国策（G3）被日频式催促——当天无 C2 执行是正常状态，看到提示不勾即可。后备设计（触发条件：上述冗余真实困扰两次）：国策定义加 `supplyBy: 'score'` 字段，评分显式动作自动为该类国策记 done（不违反"沉默是金"——显式动作有真实证据，非沉默推断）。
- **候补设计·水密隔舱/国策组（依数据准入）**：触发条件——同域国策 ≥4 条且实际发生过一次"单点失败连坐整域"的失败记录（2026-10-07 评估：当前四条全为独立根，无连坐路径，手术豁免场景已被手牌搁置语义覆盖，不满足准入）。设计要点：组 = 同父兄弟打包；组判定 N 选 M 替代单条判定（组内失败记缺席不熄灭）；组整体熄灭才连坐。

G2 设计说明（决策记录）：勿扰防"被动唤起"（通知钩子），不可用时段防"主动刷"（应用打不开，比灰度更强的近端降值）。两者与经典护眼（全天常开）完全正交，无互斥。延期密码为纸枷锁，摩擦本身有价值但不作为依赖。观察层数据支持：周均屏幕 8h22m/天，使用峰值 20:00–24:00，问题窗口与 23:00 黑窗起点吻合；20:00–23:00 为无 DDL 晚间高危区，是 C1 晚间节点与预约链的主场。

## 侦查任务（2026-10-07 软件化入役，v0.6）

- **定义**：读一道算法题 + 想清楚思路即记（不写代码），5 分钟起步——一点即记（ts 即证据，不记题号）
- **独立计数不进主链**：主链节点 = 满状态 60min 工作量证明（节点等值性是"怕失去"的根基）；侦查次数是自己的进度条（低谷在场史），**fail 不清零**（诚实记录而非欠账）
- **升级自由**：侦查中状态来了 → 随时点正式触发，无联动手续
- **零负担放弃**：坚持不了不计失败、不记次数（等于没发生）
- **不设每日上限**：滥用会自然暴露于月复盘（侦查涨、链不涨），届时走下必为例
- **与预约的分工**：预约治时间阻力（"不想现在开始"），侦查治质量阻力（"这状态守不住 1h"）——三档承诺重量：完整节点 > 预约 > 侦查，分别对应状态好/一般/差的日子
- App：链视图侦查行（active 时隐藏），按钮+计数，事件流记 `scout` 事件

## 娱乐治理条款 v1（2026-10-07 立，依据 4 周观察数据 + 成长史复盘）

**立法理由（重新归因）**：成长史显示小学-初中的交换结构运转良好（在校发奋完成→回家无负担享受→周末图书馆扫货），娱乐从未背叛本协议主体——是大学后"完成端"失去结构（无固定自习/作业可踩点/无外部监工），交换结构只剩享受半边，沦为裸奔放纵并产出羞耻。故本条款目标**不是消灭娱乐，是把'完成在前'的顺序接回去**。

**判据（两轴）**：
- 结构轴（治理对象）：有无自然单元与出口、启动成本高低——可事前判定、可环境改造，不耗意志
- 体验轴（观察对象）：沉浸 vs 解离、事后恢复 vs 空虚——仅本人可知，事后经睡前评分观察，禁止玩时实时自审（毁在场感）

**第一判据·入场时机**：娱乐好坏首看入场是否带着"完成"的收据（小学模板）——作为**心理语义保留，不设量化阈值**（设计判例 2026-10-11："周 ≥2 节点"阈值两度被问"这是什么"，一条需要反复解释的规则就是死规则，规则的可感知性是准入条件；正式删除，仅保留"完成在前、享受在后"的顺序意识）。
