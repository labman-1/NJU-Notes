# L3 作业工作稿：课程实践目标的重新梳理与 ZPD 拆分

> 来源：元认知课程第三周《0911：兴趣与内驱》（语雀 ghxd00/sqr5i3/gbv7dzs5s5300csw，2026-09-16 抓取）+ 本人背景自审（2026-09-16）+ CTDP/RSIP 方法论调研（见 [自制力方法论-全网检索与momentum分析.md](../../自制力方法论-全网检索与momentum分析.md)）。
> 写作纪律：【本人原话】【课程原文】【AI 分析】三类内容显式区分。

## 一、原始目标（本人原话）

> "结合技术支持（制作项目），有意识地调整自己的生活状态……做一个相关的项目，包含网页端、移动端（毕竟手机才是最方便的、也是对抗的主战场）。但是做完项目也许只是开始，看看这个东西能否真正解决我的痛点吧。"

## 二、对该目标的评价（对标 L3 课程理论）

### 2.1 选取得好的部分

1. **兴趣双成分齐备（Krapp 人-客体理论）**：情感性价值（"有感而发"、对方法论物理隐喻的天然亲近）+ 价值性认知（转专业备考的利害、生活状态改善的渴望）共存。按课程标准这不是娱乐（只有喜欢）也不是义务（只有重要），是能"支撑枯燥部分"的个体兴趣形态。
2. **已处于兴趣发展四阶段（Hidi & Renninger）的第三阶段**：主动调研、收集知识（精读原文 + 全网检索生态 + 逐个分析衍生项目）。课程说"知道的越多兴趣越易维持（正反馈）"——这个正反馈已经在运转。
3. **知行合一**：CAC 反复强调"必须要做事"，此目标是做事而非空想。
4. **"手机是对抗主战场"的判断准确**：与原作者"环境与触发器决定宏观稳态"的分析一致。

### 2.2 四个需要修正的问题（按课程理论逐条对标）

1. **目标层级混淆（对标 L1-L7 表）**："做一个网页+移动端 App"是 L3 应用/L6 创造层级的**工程目标**；这门课要的"课程实践目标"隐含 L7（元认知跃迁：自我觉察、心态转变）。工程目标在此只能作载体，不能作目标本身。若作业以工程目标为中心，重蹈 CAC 在 L2 反思过的"作业与所学认知割裂"问题。
2. **ZPD 超限 → 应对潜能评价不过（对标 Silvia 评价理论）**：兴趣产生需要"新颖性-可理解性"与"应对潜能（我搞得定）"两道评价同时通过。对 Web 零基础者，"网页端+移动端一步到位"在第二道评价上失败——按四阶段模型这是典型的"难度陡增而支撑不足"断裂原因。外部标尺：momentum 是 CMU 在读生做了一年多的 4MB TypeScript 项目；同理论的 Hamon 走单文件 HTML 路线照样实现核心协议。**任务必须拆到"跳一跳够得着"的粒度，否则兴趣入口变成回避入口。**
3. **需求来源倒置（对标 CAC L2 引用的课程结论）**：课程原话——"在对实践活动的反思中自然产生的需求，优先级上应该高于设想和推演中产生的需求"。我尚未实践过 CTDP 一天，此刻的全部需求来自"读文章的推演"。正序应当是：先用纸笔/现成工具（momentum 网页版）实践 → 失败记录里长出需求 → 再决定造什么。
4. **内摄调节的再生产风险（对标 SDT 动机连续体）**：我的自审原话——"忍不住娱乐，一方面清醒地批判堕落……对批判自己这种行为的自得、再到对这种自得的厌恶"——是教科书级内摄调节（内疚/自我攻击驱动）。课程明确标注：内摄调节"看起来有驱动力，实际是倦怠和心理健康问题的高风险来源"。一个 ZPD 超限的大工程大概率失败，每次失败都成为自我攻击的新素材——**项目本身会变成泥潭的一部分**。设计上必须让"失败"重新定义为"数据"（见 3.1）。

### 2.3 结论

方向选取**高度符合**个人实际（痛点真实、兴趣成分齐备、知行合一），但按 CAC 本次作业的标准（"结合课上教的知识 + ZPD"）需做三处手术：把工程目标降级为载体、把元认知目标升为北极星、把任务粒度压入 ZPD。

## 三、重新梳理的课程实践目标（三层结构）

### 3.1 北极星（L7 元认知跃迁）

**把"批判堕落的自我"改造成"采集数据的自我"。** 我晚上睡前的满足与自责，本质是对当天数据的价值判断；本学期实践的目的是把这个判断从情绪回路迁移到记录-分析回路——_RSIP 的 Roguelike 语义在此与加缪对齐：崩塌是最高效的调试器，推石上山的每一次回落都留下地形数据，内化的进度条不随重置丢失。_

**度量（主观但可追踪）**：
- 每晚睡前满足度自评 1-5 分（三行复盘的第三行）
- 周复盘中文本里"自我攻击类语句"的计数（后期可用 TF-IDF 半自动统计）
- 学期末回看：满足度曲线趋势 + 自我攻击语句频率变化 → 这是 L7 的检验证据

### 3.2 主目标（L3/L4，行为层）

用 CTDP/RSIP 方法论（先纸笔 + 现成工具，零代码）：
1. 一条主链稳定运转（目标：4 周内累计 ≥20 个有效节点，允许清零重来）
2. 建立 2-3 个能"穿越牛熊"的根国策，**健身是第一候选**（开学至今唯一存活的正行为，有存活证据的边界条件最稳）
3. 主链科目绑定转专业备考（有 DDL 的场景协议如臂使指——原作者与实践者共识）

### 3.3 载体目标（L3-L6，工程层，降级为支撑）

做一个**单文件 HTML 的 PWA**（手机浏览器打开 → 添加到主屏幕，即达成"移动端"），首版只有三个功能：
1. 主链计数（触发 → 计时 → 节点 +1）
2. 失败清零（带二次确认的判例裁决对话框：判失败 / 判允许并记录例外）
3. 三行复盘表（链状态 / 最大诱惑 / 满足度 1-5）

**功能准入门槛（铁律）**：新功能必须对应一条我自己的失败/摩擦记录（有编号），否则不进需求清单。_这正是 CAC 强调的"实践反思中自然产生的需求"。_

**明确的非目标（防需求蔓延，对标 momentum 的前车之鉴）**：
- 不做账号/云同步（momentum 的高赞 issue 一半是同步丢数据——数据意外丢失 = 外部强制的链断裂，直接摧毁判例法信任）
- 不做积分经济/押注（SDT：控制性外部事件有削弱内在动机的风险；信息性反馈优先）
- 不做宠物/成就装饰（方法论自身判定"远端加正值"增益极低）
- 数据 = localStorage + 一键导出 JSON（备份责任在我，不在服务器）

**自举设计（本项目的元认知亮点）**：开发任务本身进链管理（工程兵单元）——用 CTDP 管理造 CTDP 工具的时间。工具未成之前用纸笔链，工具成了之后迁移，迁移那天链的连续性用"下必为例"裁决一次（预期裁决：允许，因为协议本身未断，只是记录介质升级）。

## 四、ZPD 子任务拆分（按周，附层级与验证标准）

> 拆分原则：每周末可验证；每步失败都产生数据而非产生自责；工程投入时间盒每周 ≤5 小时（防吞噬）。

### W3（本周，零代码，纯实践）

| 任务 | 层级 | 验证标准 |
|---|---|---|
| T0 完成本作业文档并提交 | L2/L5 | CAC 收到 |
| T1 定义神圣座位 + 启动第一条主链（备考科目，每天目标 1 节点，"没把握不触发"） | L3 | 周末：≥3 个节点 **或** ≥1 条带分析的失败记录（两者都算达成） |
| T2 每晚三行复盘（纸笔或 Obsidian 均可） | L7 数据采集 | 7 天 ≥5 晚有记录 |
| T3 momentum 网页版试用 15 分钟，手机添加主屏幕，记录"哪一步我不愿意用" | L2/L4 | 产出 ≥3 条负样本需求（不想用 = 真实摩擦） |

### W4（评估 + 需求定稿，仍不写代码）

| 任务 | 层级 | 验证标准 |
|---|---|---|
| T1 周复盘：失败三分类（启动失败 / 中途违规 / 环境打断） | L4 | 分类覆盖全部失败事件 |
| T2 若启动失败占比 > 50%：引入预约链（15 分钟延迟） | L3 | 预约链规则一句话写清 |
| T3 需求清单 v0.1：每条需求引用失败/摩擦记录编号 | L4/L5 | 零"无案例需求" |
| T4 技术侦察：通读 Hamon 源码（单文件 HTML，量级适合首读） | L2/L3 | 能说出最喜欢与最想改的各一个设计 |

### W5-W6（MVP 开发，时间盒内）

| 任务 | 层级 | 验证标准 |
|---|---|---|
| T1 单文件 HTML：三功能（计数 / 判例清零 / 复盘表）+ localStorage + 导出 | L3/L6 | 桌面浏览器跑通；数据可导出 JSON |
| T2 开发任务进链（自举） | L3 | 工程节点 ≥4 |
| T3 PWA 化：manifest + 图标 + 手机添加主屏幕 | L3 | 手机离线可打开 |

### W7-W8（系统化 + 元认知分析）

| 任务 | 层级 | 验证标准 |
|---|---|---|
| T1 国策树上线（纸笔或 App）：健身为根国策 + 2 个零敲牛皮糖国策（如"起床 30 分钟禁娱乐 App"） | L3 | 根国策在最摆烂的一天也存活的首次证据 |
| T2 失败记录 TF-IDF 聚类（复用 Yuque Curator 的 cluster.py）——用分析社团文档的工具分析自己 | L4/L6 | 聚类出 ≥2 类主导失败模式 |
| T3 月度评价报告（L5）：系统对我有效吗？继续 / 调整 / 放弃的明确判断与理由 | L5 | 一页纸，基于 4 周数据 |

### 学期末（L7 检验）

回写本文档：预测 vs 实际（满足度曲线、链条数据、国策存活率、自攻击频率变化），完成"对认知的认知"闭环。
